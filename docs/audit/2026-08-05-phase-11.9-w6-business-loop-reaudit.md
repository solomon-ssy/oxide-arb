## 3. 仍成立的缺陷（defect-first）

### 3.1 P1 — Lease-loss 不落 durable retry（控制面）

**位置**：`crates/quant-pivot-core/src/service/feedback_scheduler.rs`

```118:131:crates/quant-pivot-core/src/service/feedback_scheduler.rs
                        Err(error) => {
                            warn!(/* ... */ "feedback scheduler lost its materialization lease");
                            break None;
                        }
                    }
                }
            }
        };
        let Some(result) = result else {
            return;
        };
```

**问题**：lease renew 失败后直接 `return`，**不**调用 `settle_retry`。materialization future 被丢弃时，pending cutoff / attempt 身份可能悬空，依赖 lease 过期后的隐式回收，而非显式 durable recovery。  
**合同**：§8 要求 lease 用于 crash/stale recovery，不能退回 process-local。  
**修复**：lease-loss 分支必须 `settle_retry`（或等价 CAS）后再返回。

### 3.2 P1 — Policy CF 生产语义仍单策略

**位置**：`feedback_attribution.rs` ≈ L2508  

生产路径仍：

```rust
let alternative_policy = AlternativeExitPolicy::LatestExecutableAtOrBeforeHorizon;
```

`FirstBarrier` 等仍偏 library/test。§4 合同若继续宣称 barrier / 多政策 missed return，则 **production-false**。  
**修复**：生产封存版本化 policy 集合；缺 baseline/depth/fee → typed `NotEvaluable`，禁止装完整。

**修复**：README 与 11.9 正文原子对齐；索引不得滞后于 canonical。

### 3.4 P2 — WS recovery 策略未单一 owner

- Feedback：`FEEDBACK_HEARTBEAT_STALE_MS=45_000`，poll 15s，visibility-gated  
- Dashboard：`DASHBOARD_WS_STALE_MS=45_000`，fallback 30s  

数值接近但 **模块分叉**。合同 §7 已写 Feedback 行为；长期应抽共享 liveness policy，避免再度漂移。

### 3.5 P2 — Feedback metrics 无专用 alert 接线

合同 §8.5 要求 quarantine / lag / overdue / gate / permit / promotion / WS recovery 有 metrics/**alerts**。  
当前 metrics 更完整，`alert_dispatcher` 未见对称 feedback 路由 → 运维闭环弱于合同。

### 3.6 P2 — 再训练 floor 策略

仅有 Conditional（drift/阈值）+ ForcedRetraining child。无独立 `ScheduledFloor`「到期必训」。  
对 prediction-market 非平稳分布，这是 **产品策略选择**，不是实现 bug；但若对外宣称「完整 CT retrain policy」，仍偏弱。建议在合同显式写死「无 floor，仅 Conditional+Forced」，或补 floor。
