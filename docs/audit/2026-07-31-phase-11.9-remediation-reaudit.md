## 1. 前序 P0 复审

### 1.1 PROMOTE-ORPHAN — **FIXED**

| 项 | 现状 |
|---|---|
| 旧 orphan service | `model_route_promotion.rs`（core service）已删除 |
| 新权威 | `ModelRouteGovernanceService`（activate / bootstrap） |
| HTTP | `POST /research/model-route-activation-permits`、revoke、`POST /research/model-route-activations`、bootstrap（`routes/feedback.rs`） |
| UI | `activatePermit` → `activateModelRoute`；issue 仍明确「不 promote」（正确两步） |
| CAS | repo 事务内 `CandidateReady → Promoted` + route generation |

设计上 permit ≠ activate（两步人工审计）是正确的 MLOps 形态，不再是“有 service 无入口”。

---

### 1.2 DSR-PBO-BYPASS — **FIXED**

DAG 现为：

```text
… → CPCV → Validation → Comparison → Shadow → Decision
```

- Validation 调用唯一 `ModelGovernancePort::evaluate_candidate(..., GateIntent::Candidate)`（`feedback_governance.rs`）。
- `DefaultModelQualityGate` 对 Candidate intent 含 DeflatedSharpe / PBO 等硬门。
- 未通过 → `ChallengerRejected` / `quality_gate_all_candidates_rejected`，不得进 Comparison / CandidateReady。
- Activation preflight 要求 frozen `quality_gate_report.passed` + report hash 进 `PromotionGateArtifact`。

**残余（可接受 / 需知情）**：activate 复核的是 **封存 Validation report**（WORM），不是阈值变更后的 live re-eval。阈值漂移应靠新 cycle，不应在 activate 时静默改门。

---

### 1.3 DUAL-PUBLISH — **FIXED**

已删除且合同禁止恢复：

```text
POST /research/models/{id}/publish
POST /research/models/{id}/bind-calibration
POST /research/models/{id}/bind-publish-path-set
```

冷启动走 `POST /research/model-route-bootstraps`（要求 `quality_gate_report.passed`）。  
ModelRouting 普通 draft mutation 禁用；rollback 仍走 config revision（文档明示，非第二套 publish）。

---

### 1.4 UNKNOWN-MARKET — **FIXED**（语义升级，非“cursor 永不前进”）

旧 bug：skip observation → 仍 advance cursor → fact 永久丢失。

新模型（§2.1 + `outcome_reconciliation.rs`）：

1. 整页 source scan → inbox + cursor **同事务**提交（observation 零丢失）。
2. 缺 catalog mapping → `Quarantined` + retry，observation 保留。
3. linkage 完成后 exactly-once 投影；TruthFreeze 对 quarantine/lag 出 typed blocker。

Cursor **会**在 inbox 持久化后前进——这是正确设计，不是旧的 lossy skip。

---

### 1.5 附带：多 intent PK — **FIXED**

- 删除 `recommendation_execution_outcome`（recommendation 级 PK 碰撞）。
- `ExecutionAttemptOutcome` PK = `order_intent_id`。
- `RecommendationExecutionRollup` 仅在全部 intent terminal 后封存；cohort 只消费 rollup。

## 3. 本轮额外增益（超出原 P0）

这些强化使闭环质量明显高于 07-30 审计时的合同：

1. **TruthFreeze**：coverage 前冻结 inbox / projector / rollup watermark；quarantine 不可填 0。  
2. **PG-backed feedback scheduler**：cadence/cooldown/lease/pause CAS；单实例拓扑写明。  
3. **Attribution 并入 11.9**（原 11.10 MERGED）：explanation / counterfactual / association / trajectory 分语义，禁因果过度宣称。  
4. **Weather 8-family**：合同要求 8/8 确定性终态，禁止 `RecognizedWeatherFamilyParserUnavailable` 长期掩盖。  
5. **ModelCandidateManifest + PromotionGateArtifact**：一次绑定 bytes/dataset/transform/calibration/CPCV/explanation/gates；封存后不可 rebind。  
6. **Serving 派生状态**：删除全局可变 publication 作为 serving truth；Inactive/Shadow/Champion 按 route generation 派生。

## 4. 仍建议处理的残余（非阻断 Implementation Closure）

### P1

1. **Operator-path E2E**：至少一条 Chromium：trigger（或 fixture CandidateReady）→ issue permit → activate → 断言 Promoted + receipt + route generation。  
2. **Governed reason 统一**：permit/activate/scheduler 与 trigger/cancel 共用同一 reason/note 合同（或服务端强校验）。  
3. **WS recovery 策略对齐**：Feedback 与 Dashboard 共享 stale/visibility policy（避免“connected but stale”只在一边轮询）。

### P2 / 知情风险

1. Activate 依赖 frozen Validation report——阈值配置变更不自动重开旧 CandidateReady（正确，但需运维知晓）。  
2. ModelRouting **rollback** 仍可改 route——需权限与审计足够硬，且 UI 深链已宣称存在。  
3. Quarantine backlog 可阻塞 TruthFreeze——要有 metrics/alert（合同 §8 已要求，需确认落地覆盖）。  
4. UI 仍可进一步复用 `QualityGateScorecard`，减少双份呈现逻辑。
