## 1. 目标与闭环定位

- 实现 ClickHouse-backed 历史 `PointInTimeDataSource` / `PointInTimeSnapshotSource`，新增
  **ClickHouse 读层**（当前仅写）。

  `ModelVersionInfo.training_dataset_id` 由裸 `Uuid` 改为 `Option<TrainingDatasetId>`。

## 6. 生产不变量与失败语义

### 6.1 Dataset lifecycle / consumer contract

状态机已由 Phase 11.6 收敛为
`Planned → Building → {Ready | InsufficientLabels | Failed}`、`Ready → Expired`。
确定性 integrity gate 在 artifact 落盘、bytes/manifest/semantic hash 与契约校验全部通过后
原子进入 `Ready`；不存在 `Built` 中间态或人工晋升。

| 状态 | artifact + PG | 下游消费 |
|------|---------------|----------|
| `Ready` | 是 | trainer / CPCV / backtest 唯一允许的输入状态 |
| `InsufficientLabels` | 是（诊断/coverage） | **禁止** train/publish；零可用 label |
| `Failed` | 是（零样本或 build 错误） | **禁止** train/publish |
| `Building` | 否（进行中） | 等待 |

`InsufficientLabels` **仍落库**诊断、coverage 与 manifest 审计信息，但禁止 train/publish；
dataset integrity gate 与 model publish quality gate 是两个独立门禁，后者不再修改 dataset 状态。

### 6.2 Determinism & parallelism invariant

- **跨 `as_of` 截面**：必须**串行**（Rank/ZScore 等 cross-sectional 因子需同截面全集）。
- **截面内**：feature resolve 可并发；factor batch 在 `features.len() >= 16` 时内部 rayon。
- **禁止**对 `group_samples` 外层按 `as_of` 做 rayon 并行。

### 6.3 其他不变量

- **零 look-ahead**：所有事实读取 `<= as_of - knowledge_lag`；`assert_no_future_leakage`
  在 artifact 落库前强校验，违例直接 fail dataset（**不** persist ledger）。
- **book JSON 解码**：`decode_levels` fail-visible；坏行计 `DatasetCoverage.book_decode_failures`
  （默认不 fail 整库；strict 模式留 3.7 gate）。
- **label 成熟度**：未成熟 label 走 `NotMature`，记录 `available_after`；settlement 未成熟不进监督列。
- **dataset/feature/factor/label schema hash 全固化**；任一输入变化必改 `dataset_hash`。
- **f64 仅矩阵边界**；NaN/inf/critical-missing 拒绝样本。
- **回测/训练禁止 live `BookStore`**：历史路径用 `PointInTimeSnapshotSource` / prefetch + materialized。
- **确定性样本计划**：相同 `DatasetPlanRequest` → 相同 `samples` 顺序与 `dataset_hash`。

## 9. Blocker

- 若 `TrainingDatasetBuilder` 读取 live `BookStore` 而非历史 PIT，本子phase失败
  （父文档 Phase 3 Blocker）。
- 若 dataset 落库未通过 `assert_no_future_leakage`，本子phase失败。
- 若 `ModelVersion.training_dataset_id` 仍是裸 `Uuid`，本子phase失败。
- 若任一 CH 读查询无显式稳定排序，本子phase失败。

## 10. 延后 / 缺口

- execution-aware label（entry/exit slippage、realized pnl）延后到 Phase 05+
  （需要真实执行历史）。
- `datafusion` SQL-like PIT 查询（父文档 §3.2）本期不引入，封装点预留在
  `QuantFactReadRepository` / `PointInTimeSnapshotSource` 之后。
- 大规模分布式 materialization 延后；本期单机 polars + 本地 Parquet。
