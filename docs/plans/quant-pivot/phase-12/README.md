## 1. 目标与范围

Phase 12 关闭三类系统性债务：

1. 删除以历史交付编号侵入生产内核的 bootstrap、命令、注释和测试；历史 Phase 文档本轮保持不动。
2. 将测试体系从“数量、忽略标记、万能 fake、shell 正则 gate”重建为 unit、contract、system、browser E2E 和只读 smoke 五类可解释验证。
3. 删除没有业务闭环的占位能力、测试专用生产 API、仪式化 crate、兼容 re-export 和历史规则脚本。

Neg Risk、官方 Rust SDK 升级和自动赎回的未来设计记录在
[`12.1-polymarket-v2-neg-risk-sdk-and-settlement.md`](12.1-polymarket-v2-neg-risk-sdk-and-settlement.md)。
Phase 12 原轮次只完成设计；用户已于 2026-07-22 显式启动独立实施。后续实现状态、证据和中断恢复只以
12.1 专项台账为准，本总账不复制其任务状态。

## 3. 状态机与原子执行规则

### 3.1 状态

| Status | 含义 |
|---|---|

`IN_PROGRESS` 计数。

### 3.2 原子完成条件

一项只能在同时满足下列条件后标记 `DONE`：

1. 目标代码或文档已完成。
2. 目标级验证通过。
3. 没有未经记录的范围扩张。
4. 本文件中的状态、完成时间和 evidence 在同一批变更中更新。
5. `git diff` 不包含用户已有修改或本项范围外修改。

### 3.3 中断恢复协议

每次开始或恢复工作必须：

1. 运行 `git status --short`。
2. 阅读本文件第一条非 `DONE`、非 `SUPERSEDED` 的本轮项目。
3. 检查实际 diff 与该项目 Target 是否一致。
4. 重跑上一条 `DONE` 项的最小验收命令。
5. 确认冻结边界未被修改后再继续。

文档状态不能单独证明完成；Git diff 和 Verification Evidence Log 必须同时存在。
