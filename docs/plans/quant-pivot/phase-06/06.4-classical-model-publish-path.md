# 06.4 — Classical Model Publish Path

> 父：[`README.md`](README.md) · [`../08-third-party-crates-and-ml-stack.md`](../08-third-party-crates-and-ml-stack.md) §5/§15
>
> 闭环定位：把 `smartcore` / `linfa` 等 classical model 从离线候选提升为可治理发布的主路径模型，
> 与 weighted scorer 共用 model registry、quality gate、shadow 和 operation log。

## 1. 目标与闭环定位

- 建立 classical model artifact 格式和 adapter。
- 支持训练产物进入 model registry，并经过 quality gate / shadow gate 后 `model.publish`。
- 发布后的 classical model 通过统一 `ModelRunner` 推理，不泄漏 crate concrete type。
- 治理 action 只使用 `model.publish`、`model.retire`、`model.rollback`。

## 2. 删除 / 合并 / 重构清单

- 删除 `research.model.*` action 旧命名，不保留 alias。
- 不允许 report composer 直接调用 `smartcore` / `linfa` concrete model。
- 不为每个算法新增一套发布 API；全部走 model registry。
- 不把 ONNX publish 和 classical native publish 混为一个 artifact type。

## 3. Artifact Contract

每个 classical artifact 必须包含：

- `model.json` 或自有二进制 artifact。
- `feature_schema.json`
- `label_schema.json`
- `preprocessing.json`
- `calibration.json`
- `training_report.json`
- `quality_gate_report.json`
- `dataset_hash`
- `artifact_hash`

若第三方 concrete model 无稳定 serde 能力，必须使用自有可审计 artifact format，或该算法不得进入生产 publish。

## 4. 配置与 feature gate

- Cargo feature：`ml-classical`，默认关闭。
- 首个主路径只允许 `smartcore` 或 `linfa` 二选一，不同时铺开。
- runtime config 只能引用已发布 model version，不存 concrete crate 参数。
- model spec 必须声明 model family、feature schema、label schema、prediction horizon。

## 5. 必建模块

```text
crates/quant-pivot-research/src/model/
├── classical.rs       # ClassicalModelAdapter trait
├── artifact.rs        # stable artifact encode/decode
└── trainer.rs         # training output -> model registry candidate

crates/quant-pivot-core/src/service/
└── model_runner.rs    # unified runner load/predict path
```

## 6. 发布流程

```text
TrainingDataset
 -> ClassicalTrainer
 -> artifact hash
 -> ModelVersion(status=candidate)
 -> QualityGate
 -> Shadow comparison
 -> governed model.publish
 -> ModelRunner hot load
```

所有 publish/retire/rollback 成功动作必须写 before/after hash。

## 7. 生产不变量与失败语义

- artifact 不可变；任何重训必须创建新 model version。
- schema mismatch 不允许 publish。
- quality gate 未通过不允许 publish。
- shadow window 未满足不允许 publish。
- publish 不得改变历史 report / recommendation。
- 推理失败必须 typed error；不产默认 score。

## 8. 验收测试

- candidate artifact hash determinism。
- unsupported serde concrete model 拒绝 publish。
- quality failed model 不能 publish。
- shadow insufficient model 不能 publish。
- publish 写 `model.publish` 且含 before/after hash。
- rollback 写 `model.rollback` 且恢复上一 published version。
- report runner 通过 unified adapter 推理，不依赖 concrete crate type。

## 9. Blocker

- 业务层直接 import `smartcore` / `linfa` concrete model，失败。
- 任何 `research.model.*` action 回归，失败。
- artifact 可被原地覆盖，失败。
- publish 绕过 quality/shadow gate，失败。
