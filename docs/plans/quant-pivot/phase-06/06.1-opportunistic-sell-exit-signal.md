## 0. 落地状态（as-built）

**已落地（`enabled=false` / `shadow_mode=true` 默认关，需 shadow + 质量门禁通过后方可生产开启）。** 与初稿的关键差异（以代码为准）：

- **模型族**：新增独立 `ModelFamily::HoldVsExitWeighted` + `ModelArtifact::SellScorer(Box<SellScorerArtifact>)`（复用 registry/artifact-store/hash/publish/quality-gate），避免与 Buy 侧 `WeightedFactor` 混淆。新增 `SellScorerRuntime` trait + `WeightedSellScorerRuntime`（输出 `SellScore{ exit_alpha_bps, p_exit_better, confidence, recommended_cumulative_exit_pct, net }`），工厂新增 `load_sell_scorer`。
- **幂等 scale-out（修复真实 churn bug）**：verdict 字段由 `sell_pct` 改为 **`target_cumulative_exit_pct`**（相对**入场 fill 冻结分母** `opportunistic_exit_state.denominator_shares` 的目标累计比例）；`quant_order_intent` 持久化 JSONB `opportunistic_exit_state{ denominator_shares, cumulative_sold_shares }`；阶梯 opportunistic 档（code ladder 第 10 档、最低非-hold 层）只卖增量 delta；**无历史 backfill**（系统未正式运行，分母在 entry fill 时写入即可）。
- **组合评估**：`CompositeExitSignalEvaluator`（reinference 优先，仅 `Holds` 才评估 opportunistic；`ThesisInvalidated`/`Indeterminate` 短路）。
- **治理指针**：`ModelConfig.active_exit_model_version_id`（`shadow_exit_model_version_id` 已删除；shadow 仅经 `opportunistic_sell.shadow_mode` + CH audit）；publish/retire 指针按 family 路由（Buy vs Sell）。
- **审计 fact**：统一 `quant_exit_signal_evaluation_event`（CH-only），同时覆盖 06.0 re-inference 与 06.1 opportunistic（含 shadow 评估）。metric `quant_opportunistic_sell_eval_total{outcome}` + `quant_exit_triggers_total{reason="opportunistic"}`。
- **离线训练平面**：`ExitFillSimulator`（depth-aware bid-walk + microstructure fallback + fee）、`HoldVsExitProceedsLabeler`（terminal hold oracle vs sim@t exit proceeds）、`TrainingSampleSource::ExitDecision`、`SellScorerTrainer`（复用 rank-IC simplex + 共享 `position_state` pseudo-factors）、`model_training` 按 family 分派且 **仅接受 ExitDecision 样本**。

### 0.1 闭环收尾（remediation，以代码为准）

初次落地后一轮深度审计补齐的闭环缺口（离线训练平面为主）：

- **离线训练真正可跑（Blocker 修复）**：`ModelTrainerService::train()` 原对所有族统一走 `rematerialize_training_examples`（强制 `HistoricalPit` + 丢弃 `position_state`/`lot_context`），会让 `HoldVsExitWeighted` 恒触发 “requires ExitDecision-only samples” 而永远训练失败。新增 exit-aware `rematerialize_exit_decision_examples`：市场因子仍走共享 `materialize_cross_section`（PIT，不信任 Parquet），但按 `(as_of, market, token)` 重挂到每条冻结 lot 行，保留其 `sample_source=ExitDecision`/`labels`/`position_state`/`lot_context`/`book_fidelity`，并重新并入 position-state pseudo-factors（避免逐-lot 标签在 `(as_of,market,token)` 键上碰撞）。
- **microstructure fallback 真正接线**：`decision_book_at` 在无 L2 深度时回退到 `as_of` 之前最新的 `book_microstructure_1s` bucket（best_bid + top-of-book USD 深度 / best_bid 折算 shares），标 `BookFidelity::MicrostructureFallback`，使 `quality_gate.sell.{min_l2_book_fidelity_ratio,max_fallback_ratio}` 门真正生效。
- **训练态防泄漏 + 费率对齐**：`peak_mark_drawdown` 改用 `[opened_at, as_of]` 的 PIT peak（不再用平仓时落库的生命周期 peak，消除早 tick 前视）；label 退出费由 `Bps::ZERO` 改为从 PIT `MarketFeeSchedule` 构造 canonical `PitFeeSchedule`，与 admission/replay/live 共用唯一公式，消除 train/serve 费率偏差。
- **output_spec 校准**：`SellScorerTrainer` 在训练标签上校准 `max_exit_alpha_bps`（realized exit-alpha 对 net 的原点 OLS 斜率）与 `p_exit_gain`（最大化 `label>0` 的 Bernoulli 似然的 logistic gain）；退化/单类样本 fail-closed 回退到 governed `conservative()`。`SellScorerArtifact::validate` 增加 `model_family == HoldVsExitWeighted` 与 `max_exit_alpha_bps > 0` 硬校验。
- **治理路由 fail-closed**：`resolve_is_exit_scorer` 在 version/spec 查不到时改为 `Err`（原 `Ok(false)` 会把 Sell 发布误挂到 Buy `active_model_version_id`）。Sell 发布额外接 shadow-overlap 稳定性门；coverage 门的 sample-count/label-coverage 对 exit 族改由 `sell.*` 阈值负责（不再用 Buy 500 样本门误卡 sell-only 数据集）。
- **审计保真**：re-inference 审计填充 `fresh_composite_score`；opportunistic 在 enabled 但打分不可用/出错路径也写 `Indeterminate` 审计行（disabled/非 auto 属结构性跳过，保持 metrics-only 以免 CH 灌水）。
- **metric 口径（以代码为准）**：`quant_exit_triggers_total{reason="opportunistic"}` 在 `CoreExitDispatcher` 成交结算（`record_exit_result`）后自增（即“确实触发并记录了退出”），而非 `decide_exit` 决策瞬间；失败/未成交的决策不计数。

## 1. 目标与闭环定位

**闭合 Phase 5 预留的 `ExitSignalEvaluator` seam 中「机会性 Sell」分支。**

05.6 已实现：

- 确定性退出优先级阶梯（emergency → SL/trailing → **ThesisInvalidated** → time → TP → partial →
  **Opportunistic 占位** → settlement hold → hold）。
- `trait ExitSignalEvaluator` + `ExitSignalVerdict{ ThesisInvalidated, OpportunisticSell{ sell_pct }, Holds, Indeterminate }`。
- `ReinferenceSignalEvaluator`（thesis-invalidation，**强制**退出，05.6/06.0 已 impl）。
- `ExitReason::Opportunistic` + `quant_exit_triggers_total{reason="opportunistic"}` metric 标签（impl 延后，metric 已注册）。

**本子phase交付：** 当 thesis **仍成立**、但模型判定「现在卖出比继续持有更优」时，产出
**advisory** `OpportunisticSell{ sell_pct }`，经 05.6 阶梯第 9 档触发 partial/full exit order。

与 ThesisInvalidated 的边界：

| 维度 | ThesisInvalidated（05.6） | OpportunisticSell（06.1） |
|---|---|---|
| 语义 | thesis 已破，**强制**退出 | thesis 仍成立，**advisory** 优化出场 |
| 优先级 | 第 5 档（高于 time/TP） | code ladder 第 10 档（最低非-hold，仅普通 kill-switch 态） |
| 模型 | re-inference 分数退化 | Sell 排序 / hold-vs-sell 效用模型 |
| fail-safe | `Indeterminate` → 不强制 | `Indeterminate` / 低置信 → `Holds` |
| kill-switch | emergency 仍走 emergency 路径 | `execution_halted` → 不自动（转人工，同 05.6 §7） |

## 5. 训练数据与标签（研究平面）

**标签定义（point-in-time，防泄漏）：**

对每个 `(market, token, entry_ts, exit_ts)` 历史 lot（来自 05.7 attribution + 05.6 realized PnL）：

```text
hold_value_at_t   = mark_price(t) × remaining_shares
exit_value_at_t   = simulated_exit_fill(t, book) − exit_fee
exit_alpha_bps(t) = (exit_value_at_t − hold_value_at_t) / cost_basis × 10_000
label_exit_better = exit_alpha_bps(t) > threshold_bps  // 分类标签
```

特征：复用 03.2 feature plane + 03.3 factors + **持仓态特征**（unrealized_pnl_pct、time_in_trade、
peak_mark_drawdown、entry_score_vs_current）。

训练流水线：03.5 dataset → 03.6 trainer（`ml-classical` 或 weighted 扩展）→ 3.7 quality gate →
publish Sell scorer artifact。

**Shadow 期（06.1 必做）：** `shadow_mode=true` 时每 tick 写 `quant_exit_signal_evaluation_event`，
对比「若按 opportunistic 退出」vs 实际 hold 的 ex-post alpha（05.7 attribution 回灌）。

## 6. 生产不变量与失败语义

- **advisory 非强制**：Opportunistic 永不 bypass SL/time/emergency；kill-switch `execution_halted` 禁止自动 opportunistic exit。
- **invalidation 优先**：同一 tick reinference 判 ThesisInvalidated 时，**不得**再评估 opportunistic。
- **fail-closed**：模型 timeout / schema mismatch / 低置信 → `Holds`（不降级为强制平仓）。
- **cadence**：复用 05.6 `signal_recheck_secs`（与 reinference 同频或独立 config `opportunistic_recheck_secs`）；
  价格类 SL/trailing 仍走 `monitor_secs` 高频。
- **realized PnL**：触发 opportunistic exit 后，R3 per-lot `apply_exit` 精确口径不变（05.6）。
- **metric**：`quant_exit_triggers_total{reason="opportunistic"}` 在 `CoreExitDispatcher` 成交结算（`record_exit_result`）后 increment（即“确实触发并记录退出”），非 `decide_exit` 决策瞬间。

- 若 opportunistic 可 bypass SL/emergency/invalidation 优先级，失败。

## 10. 延后 / 缺口（均有明确后续落点）

- **`entry_score_vs_current` 持仓态特征**（需在每个训练 tick 做 re-inference 重算入场分数 vs 当前）→ **06.5**（attribution feedback / auto-retrain，届时 re-inference 可批量回放）。本期 position-state 特征限于 `unrealized_pnl_pct` / `time_in_trade` / `peak_mark_drawdown`。
- **高保真长周期 L2 回放**（超出 `book_snapshots` 180d / `book_l2_replay_hot` 72h 的深度感知 exit-fill）→ **06.6**（book replay，已为 MAE 规划）。本期 `ExitFillSimulator` 在无 L2 时回退到 microstructure best_bid+depth，并在 dataset coverage 标记 `MicrostructureFallback` 降级行。
- **多模型 ensemble Sell**（多个 Sell scorer 投票）→ Phase 6.4+。
- **跨 lot 组合出场**（同一 token 多 lot 联合优化）→ Phase 6+ / 05.8 allocator 扩展。
- **ONNX Sell scorer** → **06.3**（`load_sell_scorer` 工厂路径已就位，新增 ONNX artifact 变体即可）。
- **Sell scorer 自动再训练**（从 shadow ex-post alpha 回灌 → dataset → 再训练治理闭环）→ **06.5**。
