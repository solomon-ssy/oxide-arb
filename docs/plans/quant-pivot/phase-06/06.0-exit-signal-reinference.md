## 1. 目标与闭环定位

**激活 Phase 05.6 预留的 thesis-invalidation 信号退出路径。**

05.6 已落地：

- `ExitSignalReinferer` seam + `ReinferenceSignalEvaluator` + `degradation_verdict` 判定准则。
- 默认 `IndeterminateReinferer`（fail-safe：信号档永不强制平仓）。
- 退出阶梯第 5 档 `ThesisInvalidated` 契约 + metric 标签。

**本子 phase 交付：** 用 **`ModelBackedExitSignalReinferer`** 替换占位 reinferer，对 open lot 做**无副作用、单市场**再推理，与 intent 冻结的 `model_version_id` + `runtime_config_version_id` + `entry_composite_score` 比较，在 `shadow_mode=false` 时真正触发第 5 档强制退出。

| 维度 | 05.6（占位） | 06.0（激活） |
|---|---|---|
| Reinferer | `IndeterminateReinferer` → 恒 `None` | `ModelBackedExitSignalReinferer` |
| 特征/因子 | 无 | `ConfiguredFeatureBuilder` + `FactorEngine::compute_all_batch`（batch=1） |
| 模型 | 无 | intent 冻结 `model_version_id` + schema binding |
| 判定 | `degradation_verdict`（已有） | 同上，不变 |
| 生产默认 | N/A | `enabled=true`, **`shadow_mode=true`**（只 audit，不 SubmitExitOrder） |
| 激活 | N/A | 运维将 `shadow_mode=false` 后 thesis invalidation 生效 |

与 Phase 6.1 Opportunistic Sell 的边界不变：06.0 只做 **thesis 破**（强制），06.1 做 **thesis 仍成立时的 advisory 卖出**。

## 2. 删除 / 合并 / 重构清单

- **删除生产默认占位：** `build_exit_monitor` 不再装配 `IndeterminateReinferer`（保留类型供 `enabled=false` 测试 / 降级语义）。
- **合并：** 单市场 feature 构建逻辑内聚于 `model_backed_reinferer.rs`（不写 PG / CH）。
- **接线：** `ExecutionBundleDeps` 新增 `research: &ResearchBundle`（model registry + factory builder）。

## 3. 新领域类型 / 表 / ClickHouse fact

### 3.1 Runtime config（新增 path）

```toml
[execution.exit_monitor.signal_reinference]
enabled = true          # false → evaluator 短路 Indeterminate（不调 reinferer）
shadow_mode = true      # true → 跑全链路 + metric/log，但 suppress ThesisInvalidated
```

挂 `ExecutionConfig.exit_monitor`（与 05.6 `ExitMonitorPolicy` 同级嵌套）。

### 3.2 无新 Postgres 表

- 再推理**不**写 `quant_model_run` / factor / feature / selection。
- Audit 先走 Prometheus：`quant_exit_signal_reinference_total{outcome=...}`。

可选后续（非 06.0 blocker）：CH fact `quant_exit_signal_evaluation_event` 与 06.1 shadow 对齐。

### 4.1 `ModelBackedExitSignalReinferer` 算法

1. 加载 intent 冻结 `runtime_config_version_id` → `RuntimeConfig`（缺失则 fail-safe 回退 live config + warn）。
2. `selected_market_for_lot(registry, lot)` → `SelectedMarket`（primary = lot 的 outcome token）。
3. `ConfiguredFeatureBuilder` + `FeatureWindowProvider` + `PitView::Live` → `FeatureVector`（`Insufficient` → `Ok(None)`）。
4. `FactorEngine::compute_all_batch(&[vector])` → ineligible → `Ok(None)`。
5. `model_registry.find(intent.model_version_id)` → `exit_model_load_ok`（Published/Retired 可加载；Draft/Rejected 拒绝）。
6. `ActiveSchemaBinding` 来自**冻结 config**（非 live config）→ `factory.load` → `infer_batch`（batch=1）。
7. `find_lot_candidate(candidates, lot)` → `FreshSignal`（含 `auto_exec_eligible`：auto_execution min_score/min_confidence）。

### 4.2 Shadow 期语义

- `shadow_mode=true`：`ReinferenceSignalEvaluator` 在 `degradation_verdict` 之后，若 verdict 为 `ThesisInvalidated`，increment `shadow_would_invalidate` 并返回 `Indeterminate`（**不**走 `decide_exit` 第 5 档 submit）。
- `shadow_mode=false`：verdict 原样传入 `decide_exit` 阶梯。
- SL / trailing / time / emergency 档**不受 shadow 影响**。

## 5. 生产不变量与失败语义

- **冻结权威：** 模型版本、config snapshot、entry score 均读 intent 冻结值，不读 live active model pointer。
- **fail-safe：** 任一环节不可用 → `Ok(None)` / `Indeterminate`；基础设施错误 → `Indeterminate` + warn（不强制平仓）。
- **schema mismatch：** factory load 失败 → `Ok(None)` + warn。
- **cross-sectional factors：** 使用 `compute_all_batch` batch=1（与单市场 report 子集一致；ZScore/Rank 在 M=1 列上仍 deterministic）。
- **cadence：** 复用 05.6 `signal_recheck_secs`；价格类 SL/trailing 仍走 `monitor_secs`。
- **metric：**
  - `quant_exit_signal_reinference_total{outcome=fresh|unavailable|error|disabled|shadow_would_invalidate|shadow_hold}`
  - 触发退出时仍 increment 既有 `quant_exit_triggers_total{reason=signal_invalidated}`

## 8. Blocker

- 若 reinferer 写 `quant_model_run` / factor / feature 行 → 失败。
- 若 `shadow_mode=false` 未跑 shadow 质量门禁即生产 → 运维流程 blocker（非代码 blocker）。
- 若 thesis invalidation 可 bypass SL/emergency → 失败（05.6 阶梯不变）。

## 9. 延后 / 缺口

- `CompositeExitSignalEvaluator`（invalidation + opportunistic）→ **06.1**。
