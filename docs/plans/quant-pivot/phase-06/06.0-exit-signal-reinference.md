### 4.1 `ModelBackedExitSignalReinferer` 算法

0. （前置门控，由 `ReinferenceSignalEvaluator` 承担）
   `intent.authorization_kind != AuthorizationKind::ActivePolicy` → 不调 reinferer，直接
   `Indeterminate`（`skipped_non_active_policy`）。
1. 加载 intent 冻结 `decision_policy_snapshot_id` → `RuntimeConfig`（**缺失/非法 → `Ok(None)`,fail-safe 持有**;不回退 live config）。
2. `selected_market_for_lot(registry, lot)` → `SelectedMarket`（primary = lot 的 outcome token）。
3. `liquidity_score_cap(config)` 无正 cap → `Ok(None)`;否则 `ConfiguredFeatureBuilder` + `FeatureWindowProvider` + `PitView::Live` → `FeatureVector`（`Insufficient` → `Ok(None)`）。
4. `FactorEngine::compute_all_batch(&[vector])` → ineligible → `Ok(None)`。
5. `model_registry.find(intent.model_version_id)` → `exit_model_load_ok`（Published/Retired 可加载；Candidate/Shadow 需质量门禁通过；Draft/Rejected 拒绝）。
6. `ActiveSchemaBinding` 来自**冻结 config**（非 live config）→ `factory.load` → `infer_batch`（batch=1）。
7. `find_lot_candidate(candidates, lot)` → `FreshSignal`（含 `route_gate_eligible`：表示新信号是否仍通过 intent 冻结 Route 的 model gate）。

### 4.2 Shadow 期语义

- `shadow_mode=true`：`ReinferenceSignalEvaluator` 在 `degradation_verdict` 之后，若 verdict 为 `ThesisInvalidated`，increment `shadow_would_invalidate` 并返回 `Indeterminate`（**不**走 `decide_exit` 第 5 档 submit）。
- `shadow_mode=false`：verdict 原样传入 `decide_exit` 阶梯。
- SL / trailing / time / emergency 档**不受 shadow 影响**。

## 5. 生产不变量与失败语义

- **active-policy-only 强制退出：** thesis-invalidation 强制平仓仅对冻结
  `AuthorizationKind::ActivePolicy` 的 intent 生效；`OperatorApproval` 持仓 →
  `skipped_non_active_policy` → `Indeterminate`。当前 entry policy 后续变化不改写该不可变授权事实。
- **冻结权威：** 模型版本、config snapshot、entry score 均读 intent 冻结值，不读 live active model pointer;
  **frozen config 缺失/非法不回退 live config**,而是 fail-safe 持有。
- **fail-safe（一律持有）：** 任一环节不可用（frozen config 缺失/非法、liquidity cap 无正值、
  feature `Insufficient`、factor ineligible、model load 拒绝、无 candidate）→ `Ok(None)` → `Indeterminate`；
  基础设施错误 / `signal_invalidation_ratio` 解析失败 → `Indeterminate` + warn（**绝不强制平仓**）。
- **schema mismatch：** factory load 失败 → `Ok(None)` + warn。
- **cross-sectional factors：** 使用 `compute_all_batch` batch=1（与单市场 report 子集一致；ZScore/Rank 在 M=1 列上仍 deterministic）。
- **cadence：** 复用 05.6 `signal_recheck_secs`；价格类 SL/trailing 仍走 `monitor_secs`。
- **config 校验：** `signal_invalidation_ratio` load 期强制 `(0, 1]`（fail-closed）。
- **metric：**
  - `quant_exit_signal_reinference_total{outcome=fresh|unavailable|error|disabled|skipped_non_active_policy|shadow_would_invalidate|shadow_hold}`
  - 触发退出时仍 increment 既有 `quant_exit_triggers_total{reason=signal_invalidated}`
