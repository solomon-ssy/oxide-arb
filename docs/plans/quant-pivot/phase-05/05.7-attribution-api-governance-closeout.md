## 1. 目标与闭环定位

1. **归因 WORM 终态写入**：`quant_recommendation_attribution` 只保存一次终态结果。
   `AttributionService` 在结果可明确归类后插入 attribution，并在同一个 PG 事务内把
   recommendation 推进到 `Attributed`。
2. **执行只读 API**：补齐 execution orders、positions、recommendation attribution 的只读
   Admin API、DTO、RBAC 和 core port。所有写入仍经执行服务、治理服务或 worker。
3. **人工禁用收敛**：彻底删除 `excluded_market_ids` 旧链路。人工禁用唯一权威是
   `MarketStatus::ManuallyBlocked`，只能通过 governed block/unblock API 改变。
4. **治理审计完整性**：`operation_log` 直接新增 `before_hash` / `after_hash`，成功治理动作必须写
   canonical before/after state hash；失败请求允许没有 `after_hash`。
5. **执行观测和分析闭环**：补齐 intent metric、ClickHouse 最终 DDL/row/writer 契约；PG 是唯一真相，
   CH 写失败只告警和计数。
6. **训练样本回灌入口**：现有 `TrainingDatasetService` 支持 `historical_pit` +
   `live_attribution` 两类样本。live attribution 样本复用 recommendation 冻结 evidence refs /
   feature vector / factor breakdown，不重新计算 PIT 特征。

完成后 Phase 05 的业务链路闭合为：

```text
RecommendationReport
 -> OrderIntent
 -> approval / admission
 -> execution / reconciliation / position lifecycle
 -> final attribution
 -> read API / audit / metrics / CH mirror
 -> training dataset sample source
```

## 2. 删除 / 合并 / 重写清单

### 2.1 删除旧 manual block 链路

- 删除 `SelectionConfig.excluded_market_ids`。
- 删除 `quant_market_selection.excluded_market_ids`。
- 删除 `SelectionExcludedMarketIds` newtype。
- 删除 `SelectionThresholds.excluded_market_ids`。
- 删除 `ManualBlockFilter`。
- 删除 `SelectorHashInput.config_excluded_market_ids`。
- 删除 config/schema/UI/docs/tests 中的 `selection.excluded_market_ids`。

### 2.2 合并人工禁用语义

- 新增 `MarketStatus::ManuallyBlocked = "manually_blocked"`。
- `MarketStatusFilter` 对 `ManuallyBlocked` 返回 `ExclusionReason::ManuallyBlocked`。
- admission `ManualBlockCheck` 的 check id 保留，输入来源改为 market status。
- `SelectionExclusionSummary.excluded_by_operator_count` 保留，统计
  `ManuallyBlocked` 状态导致的排除。
- Gamma/catalog upsert 必须 preserve `ManuallyBlocked`；解除只能走 unblock API。

### 2.3 重写 selection persistence

- `quant_market_selection` 只保存 selection summary、selector hash、config version、
  时间窗口和 `market_count`；选中市场唯一真相源是 `quant_market_selection_member`。
- 排除明细不再落单独 ID list；解释来源是成员排除 reason 和 summary。
- selector hash 只包含 selection config、data quality thresholds 和 sorted
  `selected_market_ids` 结果。

### 2.4 收敛 attribution schema

- `quant_recommendation_attribution.outcome` 使用强类型
  `RecommendationAttributionOutcome`。
- 删除 `quant_recommendation_attribution.updated_at`。
- `AttributionRepository::find_by_recommendation` 返回 `Option<_>`。
- 新增 `insert_final_and_mark_attributed(...) -> InsertFinalOutcome`：同一 PG 事务
  `INSERT … ON CONFLICT DO NOTHING`；`Written` 时推进 recommendation 状态，`AlreadyExists`
  为幂等 skip（非 error）。
- duplicate attribution 违反 WORM 约束，不更新旧行。

### 2.5 统一治理 action

- 删除旧 `research.model.*` action 字符串。
- 统一使用 `model.publish`、`model.retire`、`model.rollback`、`factor.publish`、
  `factor.retire`。
- 不保留旧 action alias。

## 4. Attribution 写入流程

新增模块：

```text
crates/quant-pivot-core/src/execution/attribution.rs
crates/quant-pivot-core/src/app/attribution_worker.rs
```

配置：

```toml
[execution.attribution]
enabled = true
sweep_secs = 60
batch_size = 100
```

处理规则：

- filled position `Closed` → `filled_exited`。
- filled position `Settled` → `filled_settled`。
- recommendation expired 且没有 fill → `expired_unfilled`。
- cancelled intent 且没有 fill → `cancelled_unfilled`。
- failed/rejected/admission-rejected/invalidated intent 且没有 fill → `failed_unfilled`。
- `Ambiguous` order、unresolved reconciliation、open/closing position 不写 attribution。

事务规则：

1. 构造 final attribution payload。
2. `insert_final_and_mark_attributed(...)` 返回 `InsertFinalOutcome`：`Written` 时在同事务
   插入 attribution 并推进 recommendation；`AlreadyExists` 为并发 sweep 幂等 skip。
3. PG 成功后 fire-and-forget 写 CH attribution event。
4. CH 失败只告警和计数，不影响 PG truth。

## 5. Operation Log 与治理收敛

`operation_log` schema/domain/API 直接新增：

- `before_hash`
- `after_hash`

hash 来源：

- 对状态对象做 canonical JSON digest。
- create 类 action：`before_hash = null`，`after_hash = created state hash`。
- update/transition 类 action：同时写 before/after。
- 失败请求：允许没有 `after_hash`，但仍记录 action / actor / reason / request id / error。

成功治理动作必须覆盖：

| Action | Hash 对象 |
|---|---|
| `system.switch_quant_mode` | `QuantModeView` |
| `system.set_kill_switch` | `KillSwitchView` |
| `runtime_config.activate` | runtime config hash |
| `runtime_config.rollback` | runtime config hash |
| `model.publish` / `model.retire` / `model.rollback` | `ModelVersionInfo` |
| `factor.publish` / `factor.retire` | factor state |
| `quant.intent.create` / `approve` / `reject` / `cancel` / `submit` | `OrderIntentInfo` |
| `quant.reconciliation.resolve` | `ReconciliationView` before/after |
| `market.block` / `market.unblock` | `MarketInfo` |
| `quant.report.revoke` | report state |

## 7. Training Dataset 回灌

只改现有 `TrainingDatasetService`，不新建训练 pipeline。

新增：

- `BuildTrainingDatasetRequest.sample_sources`
- `DatasetPlanRequest.sample_sources`
- `TrainingExample.sample_source`

默认：

```text
[historical_pit, live_attribution]
```

sample source 参与 dataset hash、Parquet、coverage。`sample_sources=[historical_pit]` 时只产历史样本。

live attribution 样本必须：

- 加载 attribution 终态 label。
- 读取对应 recommendation。
- 使用 recommendation 冻结的 `evidence_refs.feature_vector_id`。
- 复用冻结 feature vector payload / source refs。
- 复用 recommendation `factor_breakdown` 与 factor definition versions。
- 缺 frozen evidence 时 drop，并计入 coverage。
- 不重新计算 PIT 特征。

新增 labels：

- `realized_return_bps`
- `realized_pnl_usd`
- `entry_filled`
- `entry_slippage_bps`
- `max_favorable_excursion_bps`
- `max_adverse_excursion_bps`
- `missed_return_bps`
- `recommendation_outcome`

**05.7 filled-path label semantics（as-built）：**

| Label | Filled attribution | Unfilled attribution |
|---|---|---|
| `max_favorable_excursion_bps` | `intent.peak_mark_price` vs `position.avg_price`（exit monitor 维护 peak；粗粒度 MFE） | schema 含名；unfilled 写 `0` |
| `max_adverse_excursion_bps` | **`None`（非 bug）** — 无 trough 跟踪 | `0` |
| `missed_return_bps` | `0` | `recommendation.expected_return_bps` |

精确 **MAE**（filled）与更细 **MFE** 依赖 trough 或 post-outcome book replay，归
[`06.6`](../phase-06/06.6-counterfactual-factor-attribution.md) §3「05.7 label 承接」。

Schema/model：

- `quant_market_selection` 不再包含 `excluded_market_ids`。
- runtime config 不再接受 `selection.excluded_market_ids`。
- `MarketStatus::ManuallyBlocked` enum round-trip。

- duplicate attribution 不更新旧行。

API/RBAC：

- execution-orders / positions / attribution read API filter/pagination 正确。
- 未授权角色不能读取 execution/position/attribution。

Governance：

- 所有 governed success action 都有 `before_hash` / `after_hash`。
- 不再出现 `research.model.*` action。

Training：

- 默认 dataset build 同时包含 historical 和 live attribution 样本。
- `sample_sources=[historical_pit]` 只产历史样本。
- live attribution 缺 frozen evidence 时 drop 并计入 coverage。

## 10. Blocker

- 仍存在 `excluded_market_ids` 生产代码路径，失败。
- manual block 仍有 config list / runtime list 双权威，失败。
- attribution 可被 update 覆盖，失败。
- attribution 与 recommendation `Attributed` 不在同一 PG 事务，失败。
- ambiguous / unresolvable 真相写入 attribution，失败。
- 成功 governed action 缺 before/after hash，失败。
- read API 绕过 RBAC 或泄漏内部执行私有字段，失败。
- live attribution 样本重新计算 PIT 特征而不是复用 frozen evidence，失败。
