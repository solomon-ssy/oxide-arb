## 1. 目标与闭环定位

1. **attribution 写入**（父文档 §12）：每条已执行 recommendation 在结果可得后写
   `quant_recommendation_attribution`（入场/滑点/TP/SL/time exit/realized PnL/missed return/factor
   contribution after outcome），进训练样本。
2. **对外只读 API**：`GET /api/quant/execution-orders`、`GET /api/quant/positions`、
   recommendation attribution view（DTO 三层 + RBAC read）。
3. **治理收尾**：父文档 §10.1 全部 governed action（mode change / model publish-retire / factor
   publish-retire / report revoke / intent approve-reject / auto policy enable / kill-switch reset /
   manual market block / risk budget increase）均写 operation log，审计字段齐全（§10.2）。
4. **metrics 收尾**：父文档 §14 全部 9 个执行 metric 落齐。
5. **ClickHouse 镜像 fact 收尾**：执行流水 `quant_execution_event` + 资金/持仓/归因镜像 fact 落齐
   （PG 先 source of truth → CH fire-and-forget，09 §4 铁律）。
6. **验收对照**：逐条核对父文档 §15 全部 9 条验收标准（端到端测试）。

本子phase完成即 Phase 05 闭环：报告 → 意图 → 审批 → 准入 → 下单 → 对账 → 退出 → 归因 → 训练。

## 4. attribution 写入流程（父文档 §12）

触发：

- **入场后**：execution_order `Filled`/`Failed`/对账终态 → 写/更新 attribution `entry_outcome`
  （entry_filled / fill_price / fill_shares / entry_slippage_bps / filled_at）。
- **退出后**：exit 完成（Closed/Settled）或 recommendation 过期未入场 → 写 `exit_outcome` +
  `realized_pnl_usd` + `outcome`（终态）。
- recommendation status：`Executed → Attributed`（[`enums/quant.rs`](../../../crates/quant-pivot-models/src/enums/quant.rs) §71–78）。

worker：`AttributionWorker`（PeriodicTask，cadence `execution.attribution.sweep_secs`）扫描需归因的
recommendation（已执行/已退出/已过期且未归因），调 `AttributionBuilder` → `PgAttributionRepository::create`。

归因内容（父文档 §12）：是否入场 / 是否按计划入场 / 入场滑点 / 是否触发止盈 / 是否触发止损 / 是否
按时间退出 / realized PnL / missed opportunity return / factor contribution after outcome。

## 9. 生产不变量与失败语义

- **attribution 进训练样本**：归因结果是 outcome label 来源，feature schema / label schema 对齐
  Phase 3 training dataset（父文档 §12）；attribution WORM（lifecycle=audit）。
- **归因可重放**：基于 execution_order + position + recon 终态派生，确定性；同输入同归因。
- **治理审计零遗漏**：上表每个 governed action 必有 op-log（测试枚举断言）；before/after hash 覆盖
  状态变更（§10.2）。
- **只读 API 不泄漏内部**：view 隐藏 hash / 内部 id / venue 私有；分页 + 过滤稳定。
- **metric 齐全**：9 个执行 metric 全注册（启动期断言或 metrics catalog 测试）。
- **错误分层**：read API 错误经 `StorageError`/`QueryError`；归因失败不阻塞执行主路径（worker 重试）。
