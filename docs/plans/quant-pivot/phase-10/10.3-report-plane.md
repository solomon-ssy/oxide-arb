# 10.3 — Report Plane

> 父：[`README.md`](README.md) · 依赖：[`10.2-navigation-dashboard-markets-account.md`](10.2-navigation-dashboard-markets-account.md)
>
> 闭环定位：**RecommendationReport 主产物 UI**。让 `RecommendationReport` 成为前端核心页面，
> 完整展示 ranked recommendations、evidence、attribution，并作为创建 `OrderIntent` 的入口。

## 1. 目标与闭环定位

交付报告平面四块 UI：

1. **Reports 列表与 latest**：筛选、表格、latest panel、run/revoke governed actions。
2. **Report detail 与 diff**：trigger、config refs、recommendations tab、structural diff tab。
3. **Recommendation detail drawer**：score、plans、factors、evidence、attribution 全量展示。
4. **从 Recommendation 创建 Intent**：eligibility gate + governed create + 409 fail-closed。

本子phase完成后，operator 可完整消费 Phase 04 报告产物；10.4 可从 recommendation 创建 intent。

## 3. 契约与模块设计

### 3.1 Reports 列表与 latest

**筛选：** status、report_kind、trigger_kind、runtime_mode、time range。

**表格列：**

report id、as_of、runtime mode、status、top_n、published count、capital base、suggested USD、empty reason、published/revoked/expired time。

**Latest panel：** 展示最新 published report summary + 快捷跳转 detail。

**Actions：**

| Action | API | Governed |
|---|---|---|
| Run report | `POST /api/quant/reports/run` | yes |
| Revoke | `POST /api/quant/reports/{id}/revoke` | yes |

**WS：** `quant.report` → list/latest reload + toast。

**Run 202 响应：** 展示 `request_id` / `trigger_key`，非同步等待 published。

### 3.2 Report detail 与 diff

**Detail drawer tabs：**

| Tab | 内容 |
|---|---|
| Overview | trigger、source delay、horizon、account snapshot ref、runtime config version、model version、market selection、summary JSON |
| Recommendations | ranked rows：rank、market、token、side、scores、eligibility |
| Diff | 输入 other report id → `GET .../diff/{other_id}` |

**交互：**

- recommendation row click → 打开 recommendation detail drawer
- diff 只展示后端 structural diff，不做前端猜测
- diff endpoint 失败不影响 detail 主信息

**Empty report UX：**

- 明确显示 `empty_reason` 和 `status_reason`
- 不隐藏 empty 状态

### 3.3 Recommendation detail drawer

**必须完整展示的字段组：**

| 组 | 字段 |
|---|---|
| Identity | recommendation_id、report_id、rank、market_id、event_id、token_id、outcome_side |
| Score | composite、risk_adjusted、confidence、expected_return_bps、downside_bps |
| Context | market_context、liquidity_score、data_quality_score、model_score_percentile |
| Plans | entry_plan、sizing_plan、exit_plan、risk_envelope |
| Factors | factor_breakdown |
| Evidence | signal_candidate_id、feature_vector_id、model_run_id、book_snapshot_ref、runtime_config_version_id、model_version_id、factor_definition_versions、data_quality_snapshot_ref |
| Attribution | outcome、realized_pnl_usd、MAE/MFE、entry/exit outcome、attribution JSON |

**Lazy load tabs：**

- Evidence：`GET /api/quant/recommendations/{id}/evidence`
- Attribution：`GET /api/quant/recommendations/{id}/attribution`
- 无权限或不存在 → 明确 empty state

**业务目标：** 推荐详情能独立解释"为什么买、怎么买、买多少、何时退出、风险边界是什么"。

### 3.4 从 Recommendation 创建 Intent

**启用条件（全部满足才 enable 按钮）：**

| 条件 | 检查 |
|---|---|
| Permission | `order_intent:create` |
| Runtime mode | 非 `report_only`，或后端明确允许 |
| Eligibility | `execution_eligibility === eligible` |
| Validity window | `now ∈ [valid_from, valid_until]` |
| Report status | 非 revoked / expired |

**交互：**

- governed modal：展示 entry order、sizing、risk envelope hash、expires_at
- `POST /api/quant/intents`
- 409 原因原样展示

**Disabled UX（`report_only`）：**

- 按钮 disabled + tooltip 解释：不是 dry-run，当前模式不允许创建 intent
- 不误导为"模拟执行"

**成功：** 跳转或打开 `/quant/intents` 对应详情。

### 3.5 API 依赖

| Endpoint | 用途 |
|---|---|
| `GET /api/quant/reports` | 列表 |
| `GET /api/quant/reports/latest` | latest panel + dashboard |
| `GET /api/quant/reports/{id}` | detail |
| `GET /api/quant/reports/{id}/recommendations` | recommendations tab |
| `GET /api/quant/reports/{id}/diff/{other_id}` | diff tab |
| `POST /api/quant/reports/run` | run |
| `POST /api/quant/reports/{id}/revoke` | revoke |
| `GET /api/quant/recommendations/{id}` | drawer header |
| `GET .../evidence` | evidence tab |
| `GET .../attribution` | attribution tab |
| `POST /api/quant/intents` | create intent |

## 5. 生产不变量与 UX 语义

1. **Report 是主产物：** 导航和 dashboard 均指向 reports 为 primary workflow。
2. **Immutable report：** UI 不提供 edit report；只有 revoke governed action。
3. **Attribution 不在通用 audit：** 证据在 recommendation drawer，不重复建 audit 页。
4. **Money 字段：** 全部 `string` 格式化展示，禁止 JS number 运算。

## 7. Blocker

- recommendation drawer 缺少 plans 或 risk_envelope 展示 → **Blocker**
- create intent 在 `report_only` 可点击 → **Blocker**
- 仍引用旧 opportunity type 展示 score → **Blocker**
- diff 前端自行计算而非 backend endpoint → **Blocker**
