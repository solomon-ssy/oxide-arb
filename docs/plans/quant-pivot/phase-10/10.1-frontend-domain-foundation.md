## 3. 契约与模块设计

### 3.1 关键 TypeScript 类型

```typescript
type QuantRuntimeMode = 'report_only' | 'semi_auto' | 'auto_execution';

// 报告平面
interface QuantReportView { /* id, as_of, status, runtime_mode, top_n, ... */ }
interface QuantReportDetailView { /* trigger, knowledge_lag, summary, ... */ }
interface RunReportRequest { reason: string; top_n?: number; knowledge_lag_secs?: number; }
interface RunReportAccepted { request_id: string; trigger_key: string; }

// 推荐
interface QuantRecommendationView { /* rank, scores, plans, execution_eligibility, ... */ }
interface QuantEvidenceView { /* signal_candidate_id, book_snapshot_ref, ... */ }
interface RecommendationAttributionView { /* outcome, realized_pnl_usd, MAE/MFE, ... */ }

// 执行
interface OrderIntentView { /* status, approval_status, entry_order, exit_policy, ... */ }
interface CreateOrderIntentRequest { recommendation_id: string; reason: string; /* ... */ }
interface ExecutionOrderView { /* phase, venue_order_id, venue_status, state, ... */ }
interface PositionView { /* shares, avg_price, cost_usd, realized_pnl_usd, state, ... */ }
interface ReconciliationView { /* result, evidence_json, ... */ }
interface SettlementRedeemView { /* batch status, lots, ... */ }

// 账户
interface LiveAccountView { /* collateral, credential status, checked_at, ... */ }
interface EquitySnapshotView { /* equity, drawdown, ... */ }

// 系统
interface SystemStatus { /* quant_mode, kill_switch, health, ... */ }
interface KillSwitchView { /* state, changed_by, reason, ... */ }

// WS — server frame wire shape is { type, timestamp, data } (见 10.0 §3.3)；
// server control frames 复用 type: 'sync' | 'pong' | 'error'。没有 wire-level revision。
type WsServerKind = WsChannel | 'sync' | 'pong' | 'error';
interface WsFrame<K extends WsServerKind = WsServerKind> {
  type: K;
  timestamp: string; // RFC3339 millis
  data: K extends WsChannel ? WsChannelPayloads[K] : unknown;
}
type WsChannel = 'system.status' | 'system.alert' | 'market.resolved' | 'market.book_update'
  | 'config.activated' | 'quant.report' | 'quant.intent' | 'materialization.run_update';
```

**硬规则：** 所有 money/price/shares/bps/decimal wire 字段类型为 `string`，禁止 `number`。

### 3.2 API module 设计

每个 module 结构：

```typescript
// api/quant-reports.ts
export function listQuantReports(query: QuantReportListQuery): Promise<Paged<QuantReportView>>;
export function getLatestQuantReport(): Promise<QuantReportView>;
export function getQuantReport(id: string): Promise<QuantReportDetailView>;
export function runQuantReport(body: RunReportRequest): Promise<RunReportAccepted>; // governedPost
export function revokeQuantReport(id: string, body: RevokeReportRequest): Promise<void>; // governedPost
```

**`governedPost` 约定：**

- 必传 `reason` body 字段。
- 必传 header `X-Acting-Role`。
- 409/403/422 错误 detail 透传到 UI（不在 API 层吞掉）。

**`api/index.ts`：**

- 只 export 新业务 module + 保留基础 module（users/roles/menus/operation-log/runtime-config）。
- 零旧 Endgame export。

### 3.3 WebSocket 层设计

**`ws-channel-permissions.ts`：**

```typescript
const CHANNEL_PERMISSIONS: Record<WsChannel, string | string[]> = {
  'system.status': 'system:read',
  'market.book_update': 'market:read', // + scoped market_id
  // ...
};
```

**`ws-dispatch.ts`：**

- 按 channel 分发到对应 store action。
- 旧 channel case **不存在**（编译期 exhaustiveness）。
- reconnect 流程：`onConnected` → subscribe authorized → `sync` → restore market scoped。

**Store side effects：**

| Channel | Action |
|---|---|
| `system.status` | `systemStore.applyStatus` |
| `quant.report` | `quantReportStore.bumpRevision` |
| `quant.intent` | `orderIntentStore.bumpRevision` |
| `market.book_update` | `marketStore.setBook` |
| `materialization.run_update` | `researchStore.bumpRevision` |

### 3.4 Pinia store 设计

| Store | State | 禁止 |
|---|---|---|
| `system.ts` | status, kill-switch hint, mode revision, active config hint | 旧 PnL/breaker/trade balance |
| `market.ts` | scoped book cache, subscription refs | 全量 market list |
| `quant-report.ts` | last event, revision counter | report list |
| `order-intent.ts` | last event, revision counter | intent list |
| `research.ts` | materialization run event, revision | dataset/model catalog |
| `ws.ts` | connected, reconnecting, lastError | — |

页面表格数据：**页面级 query**（`useQuery` / composable），不进全局 store。
