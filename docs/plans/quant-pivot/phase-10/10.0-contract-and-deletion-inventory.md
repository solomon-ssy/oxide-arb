# 10.0 — Contract & Deletion Inventory

> 父：[`README.md`](README.md) · 概念规格：[`../10-frontend-refactor.md`](../10-frontend-refactor.md)
>
> 闭环定位：**契约冻结 / 删除清单**。冻结前端重构的全部边界——菜单、权限码、API matrix、
> WS channel、DTO 字段、删除清单、API gap——使 10.1–10.6 都建立在稳定契约上。
> 本子phase**不写业务代码**，只做设计与对照表冻结。

## 1. 目标与闭环定位

交付五类冻结物：

1. **DTO 字段清单**：确认后端 View/Request 与前端 TS type 一一对应；money/price/shares/bps 均为 `string`。
2. **菜单树 + 权限码表**：每个 seed `component` 对应真实 `views/${component}.vue`。
3. **API matrix + governed mutation matrix**：按 domain 命名 API module；标注 POST 是否走 `governedPost`。
4. **WS channel allowlist**：只允许后端已定义 channel；标注 permission、store effect、UI effect。
5. **删除清单 + API gap register**：旧 Endgame 符号全量列出；无 list endpoint 的页面不做伪列表。

本子phase完成后，10.1 可直接按契约建 types/API/store，10.2 可直接同步 menu seed。

## 3. 契约与模块设计

### 3.1 菜单树契约

所有菜单路径均为后端 seed 的最终目标。`component` 不带 `views/` 前缀、不带 `.vue` 后缀。

| Group | Path | Component | Page Permission | Button Permissions | 业务闭环 |
|---|---|---|---|---|---|
| Command Center | `/dashboard` | `dashboard/index` | mixed read | `quant_report:enqueue`, `system:switch_mode`, `system:halt`, `system:resume`, `system:emergency` | 运行模式、kill switch、WS、latest report、data quality、live account、pending intents |
| Markets | `/markets` | `markets/index` | `market:read` | `market:update` | 市场检索、订阅、YES/NO book drawer、block/unblock |
| Reports | `/quant/reports` | `quant/reports/index` | `quant_report:read` | `quant_report:enqueue`, `quant_report:revoke`, `order_intent:create` | 报告列表、latest、ad-hoc run、detail、recommendations、diff、revoke |
| Execution | `/quant/intents` | `quant/intents/index` | `order_intent:read` | `order_intent:create`, `order_intent:approve`, `order_intent:reject`, `order_intent:cancel`, `order_intent:submit` | intent 审批台和 ledger |
| Execution | `/quant/execution-orders` | `quant/execution-orders/index` | `execution_order:read` | none | CLOB submission ledger，只读 |
| Execution | `/quant/positions` | `quant/positions/index` | `position:read` | none | system lot ledger |
| Execution | `/quant/reconciliations` | `quant/reconciliations/index` | `reconciliation:read` | `reconciliation:resolve` | 对账队列、governed resolve |
| Execution | `/quant/settlement-redeems` | `quant/settlement-redeems/index` | `settlement_redeem:read` | none | 赎回批次与 lots，只读 |
| Account | `/quant/account` | `quant/account/index` | `account_snapshot:read`, `equity_snapshot:read` | none | live account、equity、drawdown |
| Research | `/research/workbench` | `research/workbench/index` | `materialization:read`, `replay:read` | `materialization:create`, `replay:create`, `publication:*`, `factor_definition:*` | dataset plan/build、train/backtest、polling |
| Governance | `/runtime-config` | `runtime-config/index` | `runtime_config:read` | `runtime_config:create`, `runtime_config:activate`, `runtime_config:rollback` | schema-driven form + JSON editor |
| Governance | `/system` | `system/index` | `system:read` | `system:switch_mode`, `system:halt`, `system:resume`, `system:emergency` | quant mode、kill switch、health、recovery |

| Admin | `/roles` | `roles/index` | `role:read` | `role:create`, `role:update`, `role:delete`, `role:assign` | 角色管理 |
| Admin | `/menus` | `menus/index` | `menu:read` | `menu:create`, `menu:update`, `menu:delete`, `permission:read` | 菜单编辑器 |
| Audit | `/operation-log` | `operation-log/index` | `operation_log:read` | none | 唯一通用审计入口 |

**命名约束：**

- `quant_report:enqueue` 替代旧 `quant_report:run`。
- `order_intent:*` 是唯一执行动作权限入口。
- 不再出现旧 `/analytics`、`/replay`、`/risk`、`/trades`、`/opportunities` 菜单。

### 3.2 API 契约矩阵

前端 API module 按业务领域命名。所有 money/price/shares/bps wire type 在 TS 中为 `string`。

| Module | Endpoints | Governed | 页面 |
|---|---|---|---|
| `api/quant-reports.ts` | `GET/POST /api/quant/reports/*`, run, revoke | run/revoke | dashboard, reports |
| `api/quant-recommendations.ts` | `GET /api/quant/recommendations/{id}/*` | no | recommendation drawer |
| `api/order-intents.ts` | `GET/POST /api/quant/intents/*` | all POST | reports, intents |
| `api/execution-orders.ts` | `GET /api/quant/execution-orders/*` | no | execution orders |
| `api/positions.ts` | `GET /api/quant/positions/*` | no | positions |
| `api/reconciliations.ts` | `GET/POST .../resolve` | resolve | reconciliations |
| `api/settlement-redeems.ts` | `GET /api/quant/settlement-redeems/*` | no | settlement redeems |
| `api/account.ts` | live, snapshots, equity-snapshots | no | dashboard, account |
| `api/markets.ts` | markets CRUD + subscribe/block | subscribe/unsubscribe/block/unblock | markets |
| `api/system.ts` | status, health, quant-mode, kill-switch, recovery | quant-mode/kill-switch | dashboard, system |
| `api/runtime-config.ts` | schema, versions, activate, rollback | create/activate/rollback | runtime-config |
| `api/research.ts` | training-datasets, models, backtest, governance POSTs | create/publish/rollback/retire | research workbench |
| `api/data-quality.ts` | `GET /api/quant/data-quality` | no | dashboard |
| `api/operation-logs.ts` | existing | no | operation-log |

**Governed mutation 必须包含：**

- report run/revoke
- market subscribe/unsubscribe/block/unblock
- intent create/approve/reject/cancel/submit
- reconciliation resolve
- runtime-config create/activate/rollback
- system mode/kill-switch/halt/resume/emergency

## 5. 生产不变量与 UX 语义

1. **零兼容**：禁止 re-export shim、旧命名 alias、mock-only 生产页面。
2. **`report_only` ≠ dry-run**：Dashboard/System 文案必须说明 credential-gated real account sizing。
3. **Governed POST**：所有真实资金/模式/kill-switch/config mutation 必须 `reason` + `X-Acting-Role`。
4. **Fail-closed 展示**：409/403/422 必须展示后端 detail，不做通用"操作失败"。
5. **WS revision only**：列表数据永远 REST query，WS 只 bump revision。

## 6. 验收测试

本子phase为设计冻结，**无代码测试**。验收方式为设计评审：

- [ ] 菜单树每个 component 有对应 view 规划
- [ ] API matrix 每个 endpoint 有 backend route 对照或 gap 标注
- [ ] 删除清单 grep 规则覆盖旧主路径
- [ ] governed mutation 矩阵完整
- [ ] API gap 每项有降级 UI 原则

## 7. Blocker

- 任一 quant 页面无法映射到 backend endpoint 且未列入 API gap → **Blocker**
- 菜单 seed 仍含旧 Endgame path → **Blocker**
- 设计项仍引用 `ExecutionMode` / `DryRun` / `Paper` / `Live` → **Blocker**
- DTO 字段清单与 backend view 不一致且未标注 gap → **Blocker**

- Research catalog/list UI **延后**至 backend list endpoint 落地（见 10.5）。
- menu seed **实施**延后至 10.2（10.0 只冻结设计）。
