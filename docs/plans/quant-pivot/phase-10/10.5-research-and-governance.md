# 10.5 — Research, Reliability & System Governance

## 1. Research Lab

`/research/lab` modules：lineage、specs、datasets、factors、models、evaluation。Research Lineage 从真实 catalog/latest records 聚合
`Spec → Dataset → Factor → Model → Evaluation → Publication`，节点打开同页 Object Inspector，再可进入 owning module。Catalog detail 使用 canonical entity id，不存在旧 model-spec/factor/dataset 独立路由。

## 2. Learning & Policy

`/research/learning-policy` modules：policies、fits、feedback、calibration。

- Policies 展示 TradePolicy lifecycle、validation rows、source slices、evidence download 与 audits。
- Fits 以 profile/cash budget/PIT cutoff/preflight 建立可执行 fit 请求，blocker 不可绕过。
- Feedback 通过 durable revision、scheduler、cycle、shadow binding、permit、activation、receipt 与 rollback 形成治理闭环。
- Calibration 只发布通过质量门并显式激活的 artifact。

WS reconnect 必须从最后持久 revision replay，再用 REST 收敛；不得把 WS payload 当成最终事实。

## 3. Data Reliability

`/research/data-reliability` modules：sources、linkages、basis-alerts、feature-integrity。

Domain source、market linkage、basis alert、parity run/event 都使用后端 typed contract。缺失、unknown category、PIT violation 与 parity latch 必须高可见度呈现；acknowledge/override/full parity run 经 governed action。

## 4. System Config

`/system/config` modules：runtime、deploy、policy、history。Policy resource 只允许六类强类型 document：recommendation、execution risk、model routing、report schedule、operations、execution automation。

生命周期为 immutable draft → validate/preflight → approve → CAS activate；rollback 复用同一 validate/approve/activate 合同。Schema pointer 与可编辑 control 必须一一对应。Deployment 只展示 redacted snapshot，不显示 secret。

## 5. System Audit

`/system/audit` modules：operations、receipts、entity-timeline。三者共用 operation log API，但拥有不同默认 filter 和标题；receipts 默认 governance category。request id、governance event id 和 resource type 可深链过滤，详情保留 actor、before/after hash、outcome 与 timestamp。

## 6. 发布证据

10 个 E2E spec 中 Research Lab、Learning & Policy + Data Reliability、Config + Audit 均使用真实 backend/DB。Config spec 通过 UI 完成 draft/validate/approve/activate/rollback，再由 REST 与 WS 验证并进入 Audit。视觉矩阵覆盖 lineage inspector、model spec、feedback loop 与 config policy 关键态。
