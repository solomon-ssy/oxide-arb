> 闭环定位：**部署配置与运行配置 UI 职责分离**。Hot-activatable runtime config 走 preferences
> schema-driven 编辑器；restart-bound deploy config 只读快照；清除 Endgame 遗留字段与 v2 兼容层。

## 1. 目标与闭环定位

交付两类配置 UI，职责不重叠：

1. **Runtime Config（热激活）**：`ui/packages/effects/layouts/src/widgets/preferences/blocks/runtime-config/` — schema 分组表单 + governed sparse patch + auto activate。
2. **Deploy Config（重启生效）**：`GET /api/system/deploy-config` — credential-masked 只读 JSON 快照，迁入 preferences 新 tab 或 `/runtime-config` 侧栏。
3. **`/runtime-config` 页**：version catalog + activate/rollback + read-only JSON diff；create-version drawer 接入。

本子 phase 不阻塞 report/execution 主路径；在 header/dashboard 控制面落地后可独立推进。

## 3. 契约与模块设计

### 3.1 Deploy Config（restart-bound）

**权威：** [`06-config-deploy-and-ops.md`](../06-config-deploy-and-ops.md) §1.1

**API：** `GET /api/system/deploy-config` — 返回 masked 子集（`polymarket`、`market_data`、`observability`、`db`、`cache`、`keys.private_key_present`、`web`）。

**故意 omitted（文档列明，不在 UI 伪造）：** `[quant]`、`[research]`、`[polymarket.relayer]`、`[market_data.data_api]` 等 — ops 直接读 `config/quant-pivot.toml`。

**UI 语义：** 只读、无 apply 按钮；标注「重启进程后生效」。

### 3.2 Runtime Config（schema v9，hot-activatable）

**API：**

| Method | Path | Permission |
|---|---|---|
| GET | `/api/runtime-config` | `runtime_config:read` |
| GET | `/api/runtime-config/schema` | `runtime_config:read` |
| POST | `/api/runtime-config/versions` | `runtime_config:create` |
| POST | `/api/runtime-config/versions/{id}/activate` | `runtime_config:activate` |
| POST | `/api/runtime-config/versions/{id}/rollback` | `runtime_config:rollback` |

**Preferences 主路径：**

- `RuntimeConfigSettings` tab（需 `runtime_config:read`）
- App-shell injection keys：
  - `RuntimeConfigRequestClientKey`
  - `RuntimeConfigGovernedKey`
  - `RuntimeConfigRevisionKey`（WS `config.activated` bump）
- Per-group dirty diff → sparse `config_patch` → governed create → auto activate
- `money_critical` 字段 extra danger + diff acknowledgment

**Schema 分组（v9 root）：** selection、data_quality、features、factors、model、quality_gate、training、reports、portfolio、execution、notification。

### 3.3 `/runtime-config` 页职责

- Version grid（masked，limit 50/200）
- Read-only JSON diff between versions
- Governed activate / rollback
- Create version drawer（schema form 或 JSON paste）— **待接入**

## 4. 推进计划

### 4.1 10.7.1 Preferences runtime-config wiring

**范围：** `web-antdv-next` BasicLayout 已 provision `RuntimeConfigGovernedKey` 等；验证 preferences tab 可 load schema + apply patch。

**验收：**

- operator（`runtime_config:create` + `activate`）可编辑并激活
- sensitive 字段 empty patch = unchanged
- activate 失败时展示「created but not activated」+ link `/runtime-config?version_id=…`

### 4.2 10.7.2 Deploy snapshot tab

**范围：** preferences 新 tab 或 runtime-config 页侧栏；只读 JsonEditorShell。

**验收：**

- `GET /system/deploy-config` 渲染 masked JSON
- 无 edit/apply 控件
- locale 说明 restart-bound 语义

### 4.3 10.7.3 Runtime-config page + create drawer

**范围：** `/runtime-config` 页 create-version drawer 接入；与 preferences 共享 schema validator。

**验收：**

- risk_owner 可从页面创建 version 并 activate/rollback
- 与 preferences 双入口不冲突（同一 governed flow）

### 4.4 10.7.4 Backend schema gap 对齐

**范围：** 阻塞 preferences 完整渲染的后端缺口。

**验收：**

- `quality_gate` group 进入 `groups_ui()`
- `when` rules 从 Rust emit 为 `FieldWhenView`
- `UiText` wire shape 在 API 边界 normalize（Rust `{ en, zh_cn }` ↔ TS `{ kind, locales }`）

## 5. 生产不变量与 UX 语义

- Deploy config **never** mutable from UI — restart-bound TOML is ops-side。
- Runtime config **never** simulates deploy fields — 两套 authority 不混用。
- `report_only` sizing 不受 runtime config UI 误导为 dry-run。
- Governed create/activate/rollback 必须 reason + acting role；money-critical 字段 danger 确认。

## 6. 验收测试

- preferences runtime-config unit tests（field-when、schema-validator、widget-registry）全绿
- manual：deploy snapshot 只读；runtime patch activate 后 WS `config.activated` toast
- lint：禁止 `risk.max_daily_loss`、v2 parser、Endgame config 符号回流

## 7. Blocker

| Blocker | 影响 | 归属 |
|---|---|---|
| `quality_gate` 未在 `groups_ui()` | preferences 缺整块 gate 字段 | backend `schema/ui.rs` |
| `when` rules 未 emit | 条件 UI 空转 | backend schema envelope |
| `UiText` shape 不一致 | 双语 label 渲染失败 | API normalize 或 TS align |
| create-version drawer 未 hook | `/runtime-config` 页只能 activate 已有 version | 10.7.3 |
