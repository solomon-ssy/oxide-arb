# 04.2 — Global Report Builder, Publisher, and Failure Lifecycle

<!-- quant-pivot-deployment-contract:v2 -->
> **Clean-break contract**：builder 生成一个跨 Route global report。旧单 Route composer、nullable model-run
> empty semantics、partial publication、solver fallback 与 recommendation 二次 sizing 全部删除。

## 1. Run lifecycle

```text
claimed
  -> freezing
  -> route_readiness
  -> candidate_economics
  -> optimizing
  -> exact_verification
  -> publishing
  -> succeeded

任何阶段 -> failed
```

`failed` 只保存 `quant_report_run`、`quant_report_route_run` diagnostics 和 operation/alert evidence；不得创建
published `RecommendationReport`、`GlobalPortfolioPlan` 或 `Recommendation`。

全部 represented Route 完整但均无候选走：

```text
candidate_economics -> publishing(valid empty artifact) -> succeeded
```

该分支必须保存每个 Route 的 zero-candidate funnel，不经过 optimizer，也不使用 solver failure/absence 作为
empty reason。

## 2. Builder pipeline

```rust
impl RecommendationReportBuilder {
    pub async fn build(
        &self,
        request: BuildReportRequest,
    ) -> QuantResult<BuildReportOutcome> {
        let boundary = self.decision_boundary.freeze(request).await?;
        let routes = self.route_readiness.resolve(&boundary).await?;
        let candidates = self.candidate_pipeline.run_all(&boundary, &routes).await?;
        let tiers = self.economic_tiers.build(&boundary, &routes, candidates).await?;

        if tiers.is_empty() {
            return self.publisher.publish_valid_empty(boundary, routes).await;
        }

        let plan = self.portfolio.solve_and_verify(&boundary, &tiers)?;
        let ranked = self.ranker.leave_one_out(&boundary, &tiers, &plan)?;
        self.publisher.publish(boundary, routes, plan, ranked).await
    }
}
```

职责边界：

- `DecisionBoundaryFreezer` 一次读取/冻结 policy、account、serving generation、Route set 与 scenario；
- `RouteReadinessResolver` 对所有 represented Route 原子核验 Champion/Calibration/Trade Policy/Research/PIT；
- `CandidatePipeline` 可并行执行 Route 内推理，但返回顺序必须 canonicalize；
- `EconomicTierBuilder` 只生成已经真实 walk 且 scenario cash-flow 完整的 tiers；
- `GlobalPortfolioPlanner` 只接收经济 tiers，不接收 raw score；
- `GlobalRecommendationRanker` 对每个 selected candidate 做 leave-one-out re-solve；
- `ReportPublisher` 是唯一可写 published artifact 的 owner。

## 3. Atomic readiness

readiness 在模型相关筛选前对完整 `RepresentedRouteSet` 执行。每个 Route 必须同时满足：

- active Champion + exact serving contract；
- compatible CalibrationArtifact + uncertainty evidence；
- Trade Policy + exit/settlement/capital occupancy evidence；
- Research Profile + feature contract + PIT lineage；
- scenario artifact 覆盖完整有序 Route set、全部 model/calibration contract 与 time bucket contract。

任一缺失使整份 run `failed`。不得跳过失败 Route、改成 pooled model、读取上一个 artifact 或发布其他 Route
的 partial report。

## 4. Empty and failure semantics

| Condition | Route outcome | Run outcome | Published report |
|---|---|---|---|
| Complete Route, no eligible market | zero candidate + funnel | continue | yes, if all contracts valid |
| Complete Route, all tiers fail economic admission | zero candidate + rejection counts | continue | yes, possibly empty |
| Discovery/source error | failed diagnostic | failed | no |
| Missing/incompatible Route artifact | readiness failed | failed | no |
| Account truth unavailable | boundary failed | failed | no |
| Solver non-optimal/timeout/numeric/infeasible | optimizer failed | failed | no |
| Exact verification mismatch | verifier failed | failed | no |
| Publication transaction error | publish failed/rolled back | failed | no |

## 5. Publication transaction

同一 PostgreSQL transaction：

1. insert immutable `quant_portfolio_plan` and verifier evidence；
2. insert `quant_recommendation_report` with route-set/scenario/account/policy hashes；
3. insert ranked `quant_recommendation` rows referencing route run and economic tier；
4. mark route runs terminal；
5. mark report run `succeeded` and enqueue outbox event。

transaction commit 后才通过 outbox 发布 API/WS/notification hint。publisher 失败必须回滚 1–5；重试使用
request/report content hash idempotency，不重复 rank 或二次求解。

## 6. Scheduler and concurrency

- schedule claim 由 PostgreSQL durable lease 保证同 cadence window 单 owner；
- manual run 与 scheduled run 共享 idempotency/content identity；
- configuration/model promotion 只影响下一次 freeze；
- cancellation 在 publication 前停止并记录 typed terminal diagnostic；publication transaction 一旦开始要么
  commit，要么 rollback；
- bounded Route workers 与 L2/economic tier capacity 必须有 timeout/backpressure/cleanup。

## 7. Recommendation composition

composer 只投影 selected `ExecutableEconomicTier`：

- exact entry VWAP/fee/slippage/shares/cash；
- Route-specific exit/settlement plan；
- `RecommendationEconomics`；
- global constraints/binding evidence；
- `RouteLineageView` 与 scenario references。

composer 不得重算 shares、USD、price、fee、probability、rank 或 constraints；也不得把 selected tier 向上/
向下 snap。

## 8. Verification

- route readiness atomicity and complete ordered Route-set tests；
- all-zero-candidate valid empty vs discovery failure tests；
- solver/verifier/publication fault injection proves no partial artifact；
- mid-run config/model activation does not change frozen hashes；
- concurrent schedule/manual request idempotency；
- transaction rollback and outbox-after-commit tests；
- selected tier economics byte-for-byte match persisted Recommendation；
- report hash deterministic across candidate/task completion order。
