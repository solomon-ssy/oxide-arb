# 04.4 — Global Report API, WebSocket, Notifications, and UI Contract

<!-- quant-pivot-deployment-contract:v2 -->
> **Clean-break contract**：wire shape 以 global economic ranking 与 per-Route lineage 为核心。旧 category
> grouped response、单 model header、`risk_adjusted_score`、Kelly provenance、partial/solver fallback report
> 均不再暴露。

## 1. Read API

```text
GET /api/quant/reports
GET /api/quant/reports/latest
GET /api/quant/reports/{report_id}
GET /api/quant/reports/{report_id}/recommendations
GET /api/quant/reports/{report_id}/route-runs
GET /api/quant/reports/{report_id}/portfolio-plan
GET /api/quant/report-runs/{report_run_id}/diagnostics
POST /api/quant/reports/run
POST /api/quant/reports/{report_id}/revoke
```

`GET /reports/{id}` 返回：

- report identity/status/as-of 与 execution eligibility summary；
- Route set/scenario/account/policy snapshot identities and hashes；
- global plan summary and constraint evidence；
- globally ranked recommendations；
- per-Route run outcomes/funnel/readiness lineage；
- valid-empty evidence when applicable。

失败 run 不出现在 published report collection；有权限的 operator 从 diagnostics endpoint 读取失败阶段、
Route、stable error code、remediation 与 evidence identities。响应不得泄漏 secret、private endpoint、solver raw
memory 或 internal credential material。

## 2. Recommendation wire shape

Money/newtype wire values 使用 decimal strings；probability 使用 bounded bps integer：

```json
{
  "rank": 1,
  "route": "weather",
  "category": "weather",
  "market_id": "...",
  "outcome": "yes",
  "economic_tier_id": "...",
  "hard_reserved_cash_usd": "125.00",
  "requested_shares": "182.4817",
  "profit_probability_bps": 6830,
  "nominal_expected_net_usd": "18.42",
  "robust_expected_net_usd": "11.08",
  "max_loss_usd": "-125.00",
  "cvar_contribution_usd": "7.16",
  "capital_occupancy_usd_hours": "930.25",
  "marginal_portfolio_value_usd": "9.73",
  "route_lineage": {}
}
```

列表默认按 `marginal_portfolio_value_usd` 的 global rank，Route/category 只作为标签和筛选器。API 不提供
category buckets 作为 canonical shape。

## 3. Mutation and RBAC

- viewer：published report/recommendation/lineage read；
- analyst：额外允许 enqueue report run；
- operator/risk owner：额外允许 revoke 与受治理 execution flow；
- failed diagnostics 仅暴露给具备 operations/research audit 权限的角色。

所有 mutation 需要 authenticated actor、acting role、reason、idempotency/CAS material，并写 operation log。
UI affordance 不能替代 server-side authorization。

## 4. WebSocket contract

WS 只发送 committed revision hint：

```text
quant.report.published
quant.report.revoked
quant.report.run_failed
quant.report.route_diagnostic_updated
```

payload 只包含 event id、report/run id、revision/status 与 occurred-at。客户端收到后重新读 HTTP canonical
resource。不得在 WS 复制完整 report、secret-bearing diagnostics 或未提交 transaction state。

SessionHub 必须保持 encode-once `ByteString` fanout、bounded queues、topic indexes 与 replay cursor 语义；事件
发布只从 committed outbox 发生。

## 5. Notifications

notification credentials/endpoints 属 Deploy Config；事件路由、severity、rate/coalescing policy 属
`operations_policy.notifications`。不得从旧 `OperationalControl` 或聚合 notification config 读取。

通知内容：

- published：report id、top economic recommendations、robust/nominal value、capital、Route tags 与内部相对链接；
- valid empty：Route funnel summary 与 explicit zero-candidate reason；
- failed：run id、failed stage/Route、stable code 与 remediation，不伪装为 empty；
- revoked/operations halt：authority/audit reference。

secret、full sensitive URL、private host、raw model payload 和 account identifiers 不进入 notification。

## 6. UI contract

Report 页面：

- global ranking table，不按 category 分组；
- Route/category filters 不改变 canonical global rank；
- economics columns 明确单位、符号与风险含义；
- details drawer 展示 Route lineage、joint scenario、capital occupancy、constraints、L2/fee evidence；
- valid empty 显示每个 Route funnel；failed run 显示 diagnostics/remediation，二者视觉和语义分离；
- desktop/tablet/mobile/light/dark/zh-CN/reduced-motion 均可用。

关键数字不可只靠颜色表达；负值、tail-risk breach、stale evidence 需要文字/icon/accessible name。表格在窄屏
使用优先级列与详情展开，不允许横向不可达 action。

## 7. E2E and screenshot gate

Playwright 真实 production-stack 场景至少覆盖：

- mixed-route global report and Route lineage drawer；
- zero-candidate report；
- missing-artifact and solver-failure diagnostics；
- viewer read-only and backend recovery；
- 390×844、768×1024、1280×720、1440×900；light/dark；zh-CN；reduced motion。

必须使用 `expect(page).toHaveScreenshot()`；关键 amount/rank/risk/lineage region `maxDiffPixels = 0`。同时
要求 axe 无 critical/serious、纯键盘完成主要 flow、无 overflow/console/pageerror/unexpected response/
requestfailed。保存 expected/actual/diff、trace、logs 和 scenario manifest；Linux Chromium 两次独立 fresh
production-stack 全矩阵连续通过。
