# 04.0 — Global Report Foundation and Contracts

<!-- quant-pivot-deployment-contract:v2 -->
> **Clean-break contract**：本文件是 Phase 04 报告基础契约。旧单 Route report header、单数 model/research
> lineage、score/confidence ranking、per-candidate sizing 与隐式 fallback 均已删除；不存在兼容 DTO、parser、
> nullable legacy column 或双写。

## 1. 目标与闭环定位

一次 report run 在同一 decision boundary 冻结全部治理、账户、Route、模型与 scenario 事实，并生成一份可
跨 Route、跨 category 的 `RecommendationReport`。Category 只用于 eligibility、risk bucket、filter 与解释；
它不是 report partition。`enabled_categories = []` 在 discovery、training、PIT、report 全链路表示全部受支持
category。

报告平面必须区分：

1. represented Route readiness/contract failure：整份 run 失败，不发布 report；
2. represented Route 完整但没有 candidate：保存 zero-candidate route outcome；
3. 全部完整 Route 均没有 candidate：可发布带完整 funnel evidence 的空 report；
4. data discovery/source failure：run 失败，不能映射为空报告。

## 2. 决策边界冻结

`ReportDecisionBoundary` 原子冻结：

- report `as_of`、schedule claim 与 request idempotency identity；
- `DecisionPolicySnapshot` 及六类 Runtime resource revision/hash；
- real `AccountSnapshot`、existing positions/exposures、available cash 与 reserve；
- `RepresentedRouteSet`、有序 Route identity 与 digest；
- `ModelServingGeneration`；
- 每个 Route 的 Champion、Calibration、Trade Policy、Research Profile、feature contract 与 PIT lineage；
- 与完整 Route set/model/calibration/time-bucket contract 兼容的 `PortfolioScenarioArtifact`；
- immutable market registry/venue lifecycle snapshot。

run 中途出现的新 activation、promotion、account refresh 或 scenario artifact 不得污染本次报告。任何冻结
identity 缺失或相互不兼容都返回 typed `ReportError`。

## 3. 公共领域类型

### 3.1 Route readiness

```rust
pub struct RepresentedRouteSet {

pub struct ReportRouteRun {
```

model availability 过滤市场再推导 Route set。

Artifact 只来自 PIT residual/calibration uncertainty、block/bootstrap、structural relation 与 explicit stress

### 3.4 Recommendation payload

`Recommendation` 必须包含：

- `report_route_run_id` 与 `economic_tier_id`；
- global rank 与 `RecommendationEconomics`；
- exact entry/sizing/exit plan；
- Route/category tags；
- `RouteLineageView`；
- selected tier 的 scenario/capital/constraint evidence references。

删除 report-level 单数 `research_profile_artifact_id`、`model_version_id`、`model_run_id`、fallback
`horizon_secs`、`risk_adjusted_score` 与 Kelly provenance。

## 4. Persistence contract

新增/收敛关系：

- `quant_report_run`：attempt lifecycle、decision boundary、failure diagnostics；
- `quant_report_route_run`：每个 represented Route 的 readiness、lineage、funnel 和 terminal outcome；
- `quant_portfolio_plan`：唯一 global plan、scenario/route/account/policy digests、solver 与 exact verifier evidence；
- `quant_recommendation_report`：仅成功发布的 artifact header；
- `quant_recommendation`：FK 到 report、route run、portfolio plan 和 economic tier。

事务边界：

1. run 与 route diagnostics 可以在失败时持久化；
2. report/plan/recommendations 必须作为同一 publication transaction 原子提交；
3. optimizer 非 optimal、timeout、numeric fault、infeasible contract 或 exact mismatch 时不得留下可读取的
   partial report/plan/recommendation；
4. zero-candidate Route 明确持久化 count/reason/funnel，不用 nullable model run 暗示。

项目没有历史生产 report；唯一 bootstrap snapshot 直接创建 `quant_report_route_run` 终态关系，不存在旧
report converter、archive 或 migration reader。

## 5. Runtime 与 Deploy owner

报告计算只消费冻结的 Runtime clean-install resources：

- `recommendation_policy`：eligibility、TopN、presentation/delivery；
- `execution_risk_policy`：budget、exposure limits、tail risk、admission；
- `model_routing`：Route bindings 与 exact scenario artifact binding；
- `report_schedule`：cadence/lease；
- `operations_policy`：pause/degradation/notification routing；
- `execution_authorization_policy`：operator-approval TTL 与 `PolicyAutomatic` per-report 上限；当前 entry policy 由 runtime control 独立拥有。

Deploy Config 只提供 restart-bound infrastructure、workers、credentials 与 capacity。账户资金与仓位不是
policy/default；只来自 credential-gated real account provider。缺 credentials 或 venue truth 时 fail closed，
不回落 configured budget/simulation。

## 7. 生产不变量

- Money/price/shares/probability/capital-time 使用 Decimal newtypes；`f64` 仅在隔离 solver coefficient
  boundary，经安全整数缩放与范围证明后使用。
- Candidate discovery 顺序不改变 Route set/report hash/selected tiers/rank。
- Ranking 使用 leave-one-out global re-solve 的 `marginal_portfolio_value_usd`，再按 robust/nominal economic
  value 和稳定 identity tie-break。
- 报告始终使用真实 account sizing；报告流水线本身不签名或提交订单，intent authority 由独立 authorization owner 决定；缺 account truth 直接 fail closed。
- 一份 report 可以包含任意 supported Route/category；UI 不按 category 强制分组。
- 任何 artifact compatibility mismatch 都失败整份 report，不允许 route-local partial publication。

## 8. 验收

- mixed Crypto/Weather/Pooled Route 进入同一 report，并按 robust economic value 排名；
- high raw score 因 fee/slippage/capital-time/tail risk 被 lower score 候选反超；
- represented Route 缺任一 atomic artifact、contract/hash/time bucket mismatch 均整份失败；
- zero-candidate、all-zero-candidate 与 discovery failure 三种语义互斥；
- small portfolio 与 brute-force optimum 一致，input reorder hash 不变；
- report/route/plan/recommendation FK、fresh-bootstrap 与 transaction rollback tests；
- solver failure 不发布 partial artifact；
- Decimal exact verifier 重算所有 recommendation economics 与 hard constraints。

## 9. Blockers

- report header 仍保存单数 model/research lineage；
- category 或 Route 仍作为 report partition；
- raw score/confidence/Kelly 进入 global objective；
- 缺 artifact、solver failure 或 account failure 被映射为空报告；
- production/backtest/replay 存在不同 allocator；
- persistence/API/UI 任一层无法追溯 recommendation 到 route run、scenario、policy/account snapshot 与
  global plan。
