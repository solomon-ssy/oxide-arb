## 1. 目标与闭环定位

Polymarket 实证显示 top 1% maker 占 ~84% 成交量（Gini ≈ 0.97），whale 系统性向小单让出 EV。
11.2.1 用 L2 book churn 作**代理**（`struct.book_churn_intensity`），语义上不能 claim 真·集中度。

本 phase 闭合：

1. **Trade-tape 摄入**：OrderFilled 级事实（maker/taker 地址、成交量、方向、token）。
2. **滚动窗口 Gini / HHI / top-1% share** 特征，在线/离线 PIT parity。
3. **因子重建**：`struct.maker_concentration` 消费真·集中度，替换 book-churn 代理在模型中的语义权重。
4. **存储与治理**：ClickHouse `quant_trade_tape` + 摄入管线；config / feature_schema 单调 bump。

**闭环回指**：回指 11.2.1 §12 文献（Polymarket-v1 Table 5）；与 11.6 training-serving parity 对齐。

## 3. 数据模型

### 3.1 ClickHouse `quant_trade_tape`

| 列 | 类型 | 说明 |
|---|---|---|
| `event_time` | DateTime64(3) | 成交时间 |
| `market_id` | String | 市场 |
| `token_id` | String | CLOB token |
| `maker_address` | String | 挂单方 |
| `taker_address` | String | 吃单方 |
| `side` | Enum8 | buy/sell（taker 方向） |
| `price` | Decimal64(8) | 成交价 |
| `size_shares` | Decimal64(8) | 成交量 |
| `notional_usd` | Decimal64(8) | USD 名义 |
| `ingestion_time` | DateTime64(3) | 写入时间 |

ORDER BY `(market_id, token_id, event_time, ingestion_time)`。

### 3.2 特征（research `features/structural/` 或新 `features/participant/`）

- `struct.maker_gini_24h` — 24h 滚动 maker 地址成交量 Gini
- `struct.maker_top1_share_24h` — top-1% maker 成交量占比
- `struct.taker_gini_24h` — taker 侧对称指标（可选）

窗口、最小样本数 config 化；样本不足 → `MissingInput`（fail-closed）。

### 3.3 因子

- `struct.maker_concentration` — 读 Gini + top-1% share，方向 **Negative**（高集中度 → fade whale 方向）
- neg-risk / binary：`NotApplicable` 规则与 11.2.1 一致

1. **源**：Polymarket Data API trades / CLOB websocket fills（需调研最新端点与 rate limit）。
