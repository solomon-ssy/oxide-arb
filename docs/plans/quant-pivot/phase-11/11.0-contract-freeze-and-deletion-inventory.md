# 11.0 — Global Portfolio Contract Freeze and Deletion Inventory

<!-- quant-pivot-deployment-contract:v2 -->
> **Clean-break contract**：本文件冻结 Phase 11 研究/模型变更与 global portfolio/report/config 的交界。
> 旧 runtime schema、单 Route serving、per-candidate sizing、solver fallback 和死字段必须迁移调用方后直接
> 删除；不建立 allowlist、alias、parser、re-export 或 feature-off production path。

## 1. Frozen invariants

1. represented Route 在模型相关筛选前计算；缺任何 Champion/Calibration/Trade Policy/Research/PIT/
   scenario binding 使整份 report run 失败。
2. Route 内生成 calibrated probability/uncertainty 与 executable cash-flow tiers；Route 间只比较统一贴现净
   USD economics。
3. direct `highs` + HiGHS 是 unconditional production/backtest/replay optimizer；build 不提供 solver feature
   selector，runtime 不提供 backend/relaxation/fallback config。
4. Report 可以跨 Route/category；category 只作 eligibility/risk/filter/explanation。
5. Runtime 只解析六类 clean-install schema `1` resource，且不存在版本分派或 converter；Deploy 只加载单个 explicit absolute file。
6. 空报告只表示所有完整 Route 无 candidate；active inference/artifact/account/solver failure 不是 empty。

## 3. Runtime v2 resource ownership

- `recommendation_policy`: selection/report presentation and delivery;
- `execution_risk_policy`: budget/exposure/tail-risk/admission;
- `model_routing`: Route Champion/calibration/trade-policy/scenario bindings;
- `report_schedule`: cadence/lease;
- `operations_policy`: pause/degradation/notifications/live operational governance;
- `execution_authorization_policy`: operator-approval TTL and `PolicyAutomatic` per-report limits; current entry policy remains a separate runtime-control fact.

Research method, calibration training method, feature contract and scenario construction method are immutable artifacts,
not hot Runtime knobs. Every resource field needs descriptor, consumer, validation, preflight, apply effect and UI pointer.

## 4. Build and dependency contract

- HiGHS native build/runtime dependency is part of the canonical production profile and CI image;
- no `lp-solver` feature can compile a different report behavior;
- model families may remain compile-time capabilities only when represented Route readiness proves exact active runtime;
- missing active model runtime fails readiness; it never generates zero recommendations;
- architecture lint rejects old symbols and multiple portfolio solver owners.

## 5. Persistence and wire contract

- old Runtime v1 JSON remains immutable audit bytes; no runtime deserialization;
- deterministic v1 fields can seed a v2 draft, but operator must fill every new risk/scenario field;
- `quant_report_route_run` owns per-Route model/calibration/research/trade-policy lineage and zero-candidate outcome;
- failed run persists diagnostics only; published wire never contains partial Route set;
- Money/probability wire and persistence remain decimal newtypes/string or bounded bps, never JS/Rust float domain values.

## 7. Verification

- compile-time exhaustiveness for six resource kinds and all API/persistence projections;
- old Runtime payloads are rejected; the six current fresh-v1 resources require exact complete values;
- missing solver/model/scenario/account causes failed run and zero published artifacts;
- production/backtest/replay produce the same plan/hash from the same frozen input;
- old symbol absence scan and architecture lint;
- Deploy/TOML descriptor audit and Runtime/UI pointer set equality;
- the sole fresh bootstrap creates the final route-run schema directly; no historical report conversion or runtime dual reader exists.

## 8. Blockers

- an old enum/config field remains constructible but has no production consumer;
- a feature flag or Runtime option changes optimizer semantics;
- any failure collapses into empty report;
- any compatibility path accepts v1 Runtime or directory/overlay Deploy config;
- docs/tests still prescribe an old path as executable behavior.
