# 11.0 — Contract Freeze & Deletion Inventory

> 关闭审计点:**#12(build/feature-gate 缺陷)**、**#23(死语义)**。是全 Phase 11 的语义精准地基。
> 本子phase**不写业务逻辑**,只冻结契约、删除死语义、硬化 build/feature-gate、落地 CI 门禁。

## 1. 目标与闭环定位

在 Phase 11 大规模改因子/模型/退出/闭环之前,先把"契约地基"钉死,避免后续子phase各自造轮子或
留死语义。三件事:

1. **删除死语义**:任何 enum 值/config 字段/DTO 字段,凡"写了但生产路径从不 emit/消费",要么在本
   Phase 有明确实现归属并登记,要么**立即删除**(零容忍向前兼容)。
2. **build/feature-gate 硬化**:部署二进制必须显式链接 `optimize`/`ml-classical`/`lp-solver`;缺失时
   **启动即失败**(fail-closed),绝不允许"报告成功但 0 条推荐"这种静默降级。
3. **锁定 runtime-config schema v10 与新枚举**:Phase 11 所有子phase新增的 config 段/enum 在此统一
   声明骨架,后续子phase只填语义,不再改 schema 版本号。

闭环定位:它是 Phase 11 依赖图的根节点(11.0 → 全部)。

## 5. 必建模块与 trait

本子phase核心产物是**CI 门禁脚本 + build 断言**,非业务 trait。

### 5.1 `scripts/lint-dead-semantics.sh`(新增)

职责:静态扫描,任何 `enum` variant / `pub` config 字段 / DTO 字段,若在 `src/`(非 test)无任何
`emit`/构造/读取点,则报错。实现方式:

- 维护一份 `docs/plans/quant-pivot/phase-11/dead-semantics-allowlist.txt`(仅允许"外部 wire 协议
  必须存在但本地不 emit"的极少数例外,每条带理由注释)。
- 脚本用 `rg` 找每个 variant 的构造点计数;计数为 0 且不在 allowlist → 失败。
- 纳入 §7 质量门禁与 CI。

### 5.2 build 断言(`app/build.rs` 扩展)

```rust
/// Fails closed at boot if a production-critical research capability was not
/// compiled into this binary. `report_only` is NOT dry-run: a build that cannot
/// optimize the portfolio or run the model runtime must never start and silently
/// emit empty reports.
fn assert_production_features() -> QuantResult<()> {
    #[cfg(not(feature = "lp-solver"))]
    return Err(InfraError::MissingBuildFeature { feature: "lp-solver" }.into());
    #[cfg(not(feature = "optimize"))]
    return Err(InfraError::MissingBuildFeature { feature: "optimize" }.into());
    #[cfg(not(feature = "ml-classical"))]
    return Err(InfraError::MissingBuildFeature { feature: "ml-classical" }.into());
    Ok(())
}
```

(`InfraError::MissingBuildFeature` 为新增 typed 变体,遵守 error layering。)

## 6. 生产不变量与失败语义

- **零死语义**:合并入 CI 后,任何新增"从不 emit 的 variant/字段"直接 CI red。
- **build fail-closed**:缺 feature → 启动失败,不降级。
- **schema 零兼容**:v9 config 加载直接 `ConfigValidation` 错误,不 shim。
- **空报告原因精准**:五种 `EmptyReportReason` 各有独立触发点与文案,禁止坍缩。

## 7. 第三方 crate 引入

无新增运行时 crate。CI 脚本使用既有 `rg`。schema 校验沿用 `schemars`。
