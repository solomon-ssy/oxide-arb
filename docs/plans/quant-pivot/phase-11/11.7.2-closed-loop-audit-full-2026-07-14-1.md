## 5. 潜在 bug / 语义风险（超出「尚未实现」）

下列项在 fitter 落地时会直接污染证据与 serving；**应在 Wave A 钉死**，而不是边写 simulator 边猜。

### R1 — Exact-tier selector 维度不完整且未共享（Blocker）

- **后果**：多维 cohort 下错误 Unavailable 或错误 Frozen；训练-服务 selector skew

### R2 — 费率曲线与官方文档对齐（High，exponent=1 时一致）

- **官方**（[Polymarket Fees](https://docs.polymarket.com/trading/fees)）：`fee = C × feeRate × p × (1 - p)`，等价 **exponent = 1**
- **代码**：
  - `execution_semantics::PitFeeSchedule::fee`：`shares × rate × [p(1-p)]^exponent`
  - `quant-pivot-api/fees/formula.rs`：同结构（注释写 `(price×(1-price))^exponent`）
  - `FeesConfig::default().exponent = 1`（`config/fees.rs`）
- **当 exponent=1**：与官方一致 ✓
- **风险**：
  - 若 `getClobMarketInfo().fd.e ≠ 1` 且写入 registry，仿真偏离官方当前公式
  - 大量 fixture/catalog 行 `fee_exponent: None`；`MarketFeeSchedule.exponent` 来源需 fail-closed 而非静默默认
  - `rebate_rate` / builder fee 未进入 `PitFeeSchedule` net walk（composer 强制 builder bps=0）
- **要求**：live fill / SDK / 官方表 property test；冻结**唯一**实现；禁止文档与代码双真

### R3 — BUY USD walk 是否含 fee（High）

- **计划/11.7**：FOK/FAK BUY amount 是 USD
- **风险**：必须与 venue/SDK `userUSDCBalance` 语义钉死并单测（总扣款 vs 名义金额）

## 8. 推荐破坏式落地顺序（可接受 breaking）

原则：先钉死金钱与账本真理，再写模拟器与统计，最后才谈激活与 UI 声称。

### Wave A — 金钱与账本真理

1. Venue 证伪费率公式（live fill / CalculatorHelper / 官方表）；单一 `PitFeeSchedule` + property tests；per-market `fd.e` fail-closed。  
2. 钉死 FOK BUY USD 与 walk 预算是否含 fee。  
3. Repository 边界实现热层+归档统一 L2/fee/metadata/resolution 批量 reader（禁 N+1、禁 core 手写 JSON/Decimal 交易）。  
4. 去掉 opportunistic cap 的 `unwrap_or(0)`；明确 runtime 仅安全上限。  
5. 抽出共享 `ExactTierSelector`（fit/backtest/shadow/composer 唯一实现）；精确校验全部 cohort 维度。  
6. `verify_frozen_dataset_artifact` + UI manifest 补齐 `trade_policy_*` 绑定。

### Wave B — Simulator 与标签

7. Typed ladder parser + trajectory builder。  
8. 完整冻结路径模拟器（gap、scale-out 固定 entry-filled denominator、trailing、invalidation、vertical、PIT resolution、`AmbiguousBarrierTouch`）。  
9. 仅从模拟器原子投影 `policy_net_*` 四标签；注册 production labeler；消除 dead-semantics FAIL。  
10. raw MFE/MAE 不被 barrier censor。

### Wave C — 统计与 artifact

11. Structural vol（DR-AS 或同等结构化估计）+ **完整** shrink_path / parent 溯源；禁跨 tier/horizon shrink。  
12. Policy CPCV（区间 purge）+ uniqueness/ESS；完整 trial ledger Parquet；DSR/PBO 用全部候选。  
13. 异步 fit stages、cooperative cancel、相同 canonical payload 幂等 artifact。  
14. Preflight 三项改为证据驱动探针（移除硬编码 `false`）。

### Wave D — 激活与 UI 诚实

15. 隔离环境首个非 synthetic `Published` cohort。  
16. dataset/model/report 绑定；ReportOnly **policy** shadow（非仅 model shadow）。  
17. SemiAuto approve→arm→exit→attribution E2E（走 `TradePolicyService::transition`，非 repository 绕过）。  
18. **在声称激活前**：Workbench Incomplete / shadow-only banner；policy evidence scorecard；blocker i18n 全量对齐；Frozen recommendation 展示 policy provenance；列表 publishable 信号。
