# 11.2 — Polymarket Vertical Alpha

> 关闭审计点:**#4(垂直/领域信号完全缺席:domain feature 恒 `DomainDataMissing`、
> `DomainFactorRegistry` 从不注册、`FactorRegistry::build` 不挂载;Polymarket 真实边缘一个都没有)**。

## 1. 目标与闭环定位

给系统装上**Polymarket 特有的结构性与领域性阿尔法**,而不只是通用微结构因子。它把在线因子层从
"platform-agnostic 微结构排序"升级为"prediction-market-aware 排序",并激活 `DomainFactorRegistry`
的按 category 路由。

设计立场(有实证支撑):Polymarket 存在可利用的系统性偏差与结构性约束。核心证据:

- **Favorite-longshot reversal**:Polymarket 低概率 token 系统性被**高估**(负实现收益)、高概率 token
  被**低估**(正实现收益),retail 系统性高估尾部结果。见 *Polymarket-v1 Database*(arXiv)
  <https://arxiv.org/html/2606.04217v1> 与 *How Wise is the Crowd?* <https://doi.org/10.5281/zenodo.18821864>。
  注意:该偏差**并非每个市场都存在**,需按 category / 是否控制 time-to-resolution 做条件化;论文指出
  它在部分市场可能是"Yes Bias"的统计假象。因此因子必须**条件化 + 可开关 + 经 IC 验证**,不能无脑套用。
- **Neg-risk 结构约束**:多结果事件(3+ outcomes)走 Neg Risk CTF Exchange;各腿 YES 之和应 ≈ 1,
  漂移即结构性错价;NO 可通过 Neg Risk Adapter 转成其余全部 YES(capital efficiency 边缘)。见
  <https://docs.polymarket.com/trading/orders/overview> 与 <https://polymarkets.co.il/en/bots/polymarket-negrisk-execution/>。
- **强反转性 / 参与者集中**:大幅波动后 24–48h 显著回补;top 1% maker 占 84% 成交(Gini 0.97),
  whale 系统性向小单让出 EV。见 arXiv Table 5 与 beatpoly crowd-psychology 综述。

闭环定位:11.1(通用因子地基)→ 11.2(领域/结构因子)→ 11.4(训练把两类因子一起学权重)。

## 3. 契约与算法设计

### 3.1 结构性因子(平台内可算,不依赖外部数据)

这些是 Phase 11 首批落地(无需接外部数据源即可产出真实边缘):

| 因子 | category 适用 | 定义 | 经济含义 / 证据 |
|---|---|---|---|
| `struct.favorite_longshot` | 全体(条件化) | 以 mid 价所在概率分位映射到经验校准偏差表(11.3 校准产物),输出 `E[bias]` | 校正 retail 尾部高估;arXiv reversal |
| `struct.negrisk_leg_sum_drift` | neg_risk=true | `Σ best_ask(all YES legs) − 1`(或 bid/mid 版本) | 多腿和偏离 1 = 结构性错价;Polymarket neg-risk |
| `struct.negrisk_convert_edge` | neg_risk=true | `cost(buy YES basket) − cost(NO_favorite via adapter)` | 转换套利式 capital-efficiency 边缘 |
| `struct.reversal_after_shock` | 全体 | 近窗大幅单边移动后的反转打分(基于 §11.1 reversal + 时窗) | 58% 大移动 48h 内部分回补 |
| `struct.resolution_proximity_regime` | 全体 | time_to_resolution 分桶 × 价格分位交互 | 临近 resolution 的定价成熟度差异 |
| `struct.maker_concentration_proxy` | 全体 | 用 book churn / 大单占比近似 maker 集中度 | 集中做市 → 结构性 taker 劣势/优势 |

> 关键:`struct.favorite_longshot` **依赖 11.3 的校准表**(经验概率 vs 市场价),故 11.2 与 11.3 有
> 双向依赖;落地顺序:11.3 先产出校准 artifact,11.2 消费之。README 依赖图已体现 11.1→11.3、
> 11.1→11.2;此处补充 11.3→11.2(favorite_longshot 因子)。

### 3.2 领域性因子(需外部数据,接口先行、加性扩展)

沿用 [`phase-03/03.8`](../phase-03/03.8-vertical-domain-closed-loop.md) 的垂直闭环范式
(Crypto 参考垂直:linkage + domain PIT + 两层向量 + ModelRouting)。11.2 **不重复造 03.8**,而是:

- 把 03.8 的 Crypto 垂直因子**真正注册进 `DomainFactorRegistry`** 并按 category 路由(修复 #4 的
  "从不注册")。
- 为 sports/politics/weather/geopolitics 保留接口;外部数据不可用时走 `DomainMissing`(不阻塞通用报告)。
- 明确:结构性因子(§3.1)**平台内可算,本 Phase 必须落地**;领域性外部因子(§3.2)按数据源接入
  逐步开启,是加性能力。

### 3.3 因子路由

```rust
/// Routes structural/domain factors by market category and market structure flags.
pub trait DomainFactorRouter {
    fn factors_for(&self, category: MarketCategory, neg_risk: bool) -> Vec<FactorId>;
}
```

`FactorRegistry::build` 调用 router,把 §3.1 结构因子(全 category)+ §3.2 领域因子(按 category)
注册进统一 engine。neg-risk 专属因子只对 `neg_risk=true` 市场计算,否则 `NotApplicable`(非 missing、
非 0)。

## 6. 生产不变量与失败语义

- **条件化 + IC 验证**:favorite-longshot 等偏差因子必须按 category 分别验证 IC 符号与显著性(11.5),
  IC 不显著的 category 自动关闭该因子(避免把"统计假象"当边缘)。
- **neg-risk 正确性**:neg-risk 因子必须读 `market.neg_risk`(源自 Gamma),不得按标题猜测(与执行侧
  11.7 的 negRisk flag 传递一致)。
- **不静默**:缺腿/缺外部数据 → `Indeterminate`/`NotApplicable`/`DomainMissing`,各有独立语义。
- PIT:neg-risk 全腿 book 必须同一 `as_of` PIT 解析。

- 领域性外部数据源:遵循 03.8 的数据源选型,不在本 Phase 引入新 ML crate。
