## 1. 目标与闭环定位

本期不是修补两个局部缺口，而是关闭以下完整证据链：

```text
决策时钟 → PIT selection → metadata/book/domain → FeatureCell → factor/model input
→ frozen dataset → training/CV → serving → runtime parity → 告警/撤销/恢复
```

已经确认的根因必须一起消除：

- report 先减一次 delay，domain/window 查询又减一次，形成 source delay 双减；live book 还可能忽略 cutoff。
- 历史查询读取当前 `market/event` 投影，当前 metadata 被错误地冒充历史真值。
- `empty_book`、`stub_market_context`、空 registry/default staleness 把缺证据伪造成合法市场状态。
- classical 训练填 0、服务填均值；Bps 在训练和服务之间可能相差 10,000 倍。
- dataset artifact 已冻结，训练时却用当前代码重新物化并覆盖其中的 feature/factor。
- category model 失败静默回退 generic；classical 被无关 factor pipeline 强耦合。
- `HistoricalQuantile` 在线读取可变历史，既无法绑定训练分布，也无法可靠复现模型语义。

生产判定采用三个互不替代的概念：

1. **确定性 parity（11.6）**：同一冻结证据、契约和模型必须产生相同结果；不一致是工程故障。
2. **数据/概念漂移（11.9）**：不同时段的分布或效果发生变化；它触发 challenger，不证明工程 skew。
3. **模型质量（11.3/11.5/11.9）**：校准、CPCV/DSR/PBO 和 champion-challenger gate。

结构性依据：保存 serving 特征、复用 train/serve 转换并要求相同样本得分一致，见
[Google Rules of ML](https://developers.google.com/machine-learning/guides/rules-of-ml/)；PIT join 只能读取实体
时点之前已可见的版本，见 [Feast point-in-time joins](https://docs.feast.dev/getting-started/concepts/point-in-time-joins)；
拟合统计量必须随模型 artifact 发布，见
[TensorFlow Transform best practices](https://www.tensorflow.org/tfx/guide/tft_bestpractices)；插补必须配显式状态，见
[scikit-learn MissingIndicator](https://scikit-learn.org/stable/modules/generated/sklearn.impute.MissingIndicator.html)。

## 2. 删除 / 合并 / 重构清单

| 对象 | 问题 | 本期唯一处置 |
|---|---|---|
| 新建平行 `FeatureContract` 的旧草案 | 与现有 `FeatureSpec/FeatureSchema` 重复，会产生第二份语义 | **删除该设计**；只扩展现有 schema，增加 `compute_revision` 并把实现语义纳入 hash。 |
| 平行 `HistoricalRegistryResolver` | 继续保留 live/historical 双实现 | **不建设**；统一为 durable `PointInTimeSnapshotSource`。 |
| legacy `PitView::{Live, Historical}`、`resolve_registry`（已删除） | 双路径字段能力不同 | selection、feature、capture 统一共用一份 immutable `ResolvedMarketSnapshot`，禁止恢复旧分叉。 |
| `empty_book`、`stub_market_context`、registry `None` 默认 | 伪造 Active/false/2/空字符串/新鲜度零 | **删除**；storage seam 的 `Option` 只表示“没有版本”，关键 snapshot 缺失直接报 PIT error，feature-level 缺失统一落为有原因的 `FeatureCell`。不再额外建设通用 `Resolution<T>`。 |
| 当前 `market/event` 投影参与 replay | 当前状态冒充历史 | replay 禁止读取；新增 append-only catalog version ledger。 |
| `fill_missing`、`.__available` 字符串协议 | train/serve 两套缺失处理，且 ordinal state 丢语义 | **删除**；由共享 fitted transform 输出强类型 encoded columns。 |
| dataset 训练时 rematerialize 并替换 frozen rows | artifact 不再是训练真值 | **删除替换路径**；rematerialization 只可作为 parity verification。 |
| legacy `Built`、人工 `promote_dataset_ready`（已删除） | 完整性门禁与人工状态重复 | lifecycle 已收敛为自动 integrity gate 后 `Ready`，禁止重新引入人工晋升。 |
| category → generic fallback | 路由故障被伪装成成功 | **删除**；加载、scope、inference 任一失败使整轮报告失败。 |
| classical 调用 factor plane、synthetic model input run id | 无关耦合、证据链断裂 | 按 family 分派；所有 runtime input 使用真实持久化 `model_run_id`。 |
| `HistoricalQuantile` + inference `recent_values` | 服务分布可变、无法绑定 artifact | 替换为 artifact 内 `FrozenReferenceQuantile`。 |
| mutable factor definition 覆盖旧定义 | 同 ID 混入不同语义的历史值 | 改为 content-addressed immutable revision；logical name 仅作治理分组。 |
| 可关闭的 historical strict / 全局 classical missing config | 允许 runtime 改写模型契约 | **不新增**；PIT 严格性是系统不变量，missing policy 属于 feature/model contract。 |

不建设通用 Feast/Tecton 式 feature-store 产品，也不增加第二套 feature registry。现有 schema、durable
facts、catalog ledger、frozen artifacts 和 parity ledger 足以形成项目内闭环。

## 3. 新领域类型 / 表 / ClickHouse fact

### 3.1 时间与快照契约

```rust
pub struct DecisionBoundary {
    decision_at: DateTime<Utc>,
    knowledge_cutoff: DateTime<Utc>,
    knowledge_lag_secs: u64,
    per_source_cutoffs: BTreeMap<DecisionSource, DateTime<Utc>>,
}

pub struct ResolvedMarketSnapshot {
    pub boundary: DecisionBoundary,
    pub market: Arc<MarketRegistryInfo>,
    pub event: Arc<EventRegistryInfo>,
    pub context: MarketContextAt,
    pub neg_risk_leg_set: NegRiskLegSet,
    pub catalog_sync_batch_id: CatalogSyncBatchId,
    pub market_catalog_version_id: MarketCatalogVersionId,
    pub event_catalog_version_id: EventCatalogVersionId,
    pub market_content_hash: ContentHash,
    pub event_content_hash: ContentHash,
}

#[async_trait]
pub trait PointInTimeSnapshotSource {
    async fn books_at_boundary(/* ... */) -> QuantResult<HashMap<TokenId, BookSnapshotAt>>;
    async fn market_snapshots_at_boundary(
        &self,
        boundary: &DecisionBoundary,
    ) -> QuantResult<Vec<ResolvedMarketSnapshot>>;
}
```

`ResolvedMarketSnapshot` 只承载 catalog/event 的原子版本及其 hash；book 由同一 boundary 的批量读取返回。
报告轮次随后把二者冻结进 `DecisionSnapshotSource`，selection、feature 与 capture 只读这一份不可变内存投影。
domain/window 同样按 boundary 批量预取，但不伪装成 catalog snapshot 字段。底层 `Option`/map omission 不携带
业务默认：关键 primary book/catalog 缺失立即 `PitResolution`，可选 feature 证据缺失才进入 `FeatureCell`。

- `decision_at = trigger_time`；唯一构造器计算 `knowledge_cutoff = decision_at - knowledge_lag`。
- 每个 domain cutoff 取全局 cutoff 与该来源 availability lag 的更早者；下游不得再次减 lag。
- 查询同时约束 `source_effective_at <= source_cutoff` 与 `available_at/ingestion_time <= decision_at`，
  再按 effective time、available time、stable ID 确定性排序。
- 研究/报告链路的模糊 `as_of` 破坏式重命名为 `decision_at`；旧的模糊 delay 字段统一为
  `knowledge_lag_secs`。
- `valid_from = published_at`；目标上界仍是 `decision_at + prediction_horizon`，再受 market end/risk
  policy 收窄。发布时已不足最低可操作窗口则失败，不延长预测期限。

### 3.2 Feature 与模型输入契约

现有 `FeatureSpec` 是唯一 schema；新增 `compute_revision` 并纳入 `feature_schema_hash`。schema 构造遇到
duplicate name 必须失败。删除全局 `critical`，固有缺失语义由 `NullPolicy` 表达，模型是否必需由
`ModelInputContract.requiredness` 表达。

```rust
pub struct FeatureCell {
    pub state: FeatureCellState,
    pub value: Option<FeatureValue>,
    pub reason: Option<NullReason>,
    pub evidence: Option<EvidenceSourceRef>,
    pub staleness: FeatureStaleness,
}

pub enum FeatureCellState {
    Observed,
    Substituted,
    Missing,
    NotApplicable,
}

pub struct ModelInputContract {
    pub inputs: Vec<ModelInputSpec>,
}

pub struct FittedInputTransform {
    pub inputs: Vec<FittedInputColumn>,
    pub encoded_columns: Vec<EncodedColumn>,
}
```

median/mean/std、category vocabulary 与 state rates 位于每个 `FittedInputColumn`；contract/transform hash 由
`FittedInputTransform` 的 canonical 方法计算，`training_input_hash` 与这些 hash 一起绑定在 model artifact，
而不是复制为 transform 内的可漂移字段。

- unknown staleness 必须是 `FeatureStaleness::Unknown`，future timestamp 和 duration/number 转换错误必须失败。
- Polymarket market 固定二元，删除无信息量 `outcome_count` feature；neg-risk event leg count 是独立结构特征。
- optional numeric 只用 fold train 的 `Observed` 值拟合 median；无 observed 值失败。每个 value 后输出
  missing / not-applicable / substituted 三个非缩放 Boolean indicator。
- Bps 只在共享 transform 转为 ratio（`/ 10_000`）；category 使用冻结 one-hot vocabulary 和
  `__unknown`，禁止矩阵静默忽略。
- numeric scaler 只在 fold train 拟合；zero variance、non-finite、shape、duplicate column、Decimal↔f64
  转换失败均拒绝。

### 3.3 持久化

Postgres 新增：

- `catalog_sync_batch`：同步模式/cursor、fetched/committed time、计数、状态、batch hash。
- `event_catalog_version`：event 完整规范化状态、membership、source effective/available time、origin、hash。
- `market_catalog_version`：identity/token/outcome/category/status/neg-risk/fee/tick/min-order/liquidity/volume、
  source timestamps、event version、hash。
- `quant_feature_parity_run`：run kind/window/contract/transform/status/counts/result/audit。
- `quant_feature_parity_state`：单例 latch、触发 run、影响窗口、ack actor/reason、恢复 run。
- `quant_feature_vector`：保存完整 `decision_boundary`；旧行可为 `NULL` 仅供审计，禁止 replay。model/run 与
  runtime/transform fingerprint 分别由下面的 stateful CH facts 绑定，避免把一个可复用 raw vector 错绑到单一模型。

ClickHouse 调整/新增：

- `quant_feature_event` 升级为包含 `FeatureCell` state/reason/evidence 的全量事实。
- `quant_model_input_event` 保存真实 route/run、ordered encoded input 和 transform fingerprint。
- `quant_serving_evidence_completion`：只有 feature/model-input 批次均获持久化 ACK 后才写入的 run-level barrier；
  model run 在它落地前不得成功。
- `quant_feature_parity_event` 保存每个 sampled/full comparison 的 stage、左右 fingerprint 与 mismatch reason。

Gamma 同步必须在同一事务写 batch、version rows 和 latest projections，提交后才发布到 in-memory
registry/cache/subscription；删除 best-effort persistence。第一次成功同步建立 `catalog_coverage_start`：旧当前行
只允许以切换时 `available_at` 形成首版，绝不 backdate；coverage start 之前的 replay 明确失败。

## 5. 必建模块、数据流与页面

### 5.1 Frozen dataset 与共享转换

- Parquet v2 保存 boundary、完整 FeatureCell、immutable factor revision/raw value、label、source fingerprint
  和 manifest。训练校验 bytes hash、manifest hash、semantic dataset hash 和契约绑定后，直接消费这些行。
- lifecycle 为 `Planned → Building → Ready | InsufficientLabels | Failed`，`Ready → Expired`。所有训练、
  校准、CPCV、backtest 只接受 `Ready`。
- 每个 CV fold 独立 fit `FittedInputTransform`；最终模型在最终训练分区重拟合。classical artifact 还保存
  estimator bytes hash、registry family 与 crate ABI，加载时做深度验证。

### 5.2 Factor 与 serving

- factor definition ID 由 canonical definition + feature contract hash 派生；同 logical name 可有多个 immutable
  revision，但最多一个 Published，发布新 revision 时事务性 retire 旧版。
- `FrozenReferenceQuantile` 的 reference CDF 只从 fold train 拟合，最终 CDF 写入 weighted artifact；serving
  不再查询 `recent_values`。
- ModelRunner 先验证全部 routes，再按 family 分派：weighted 才走 factor pipeline，classical 直接应用
  frozen transform，category pointer 任一失败整轮失败。
- 未绑定可信 probability→return/downside calibration 的 classical model 标为 `ShadowOnly`，阻止 publish；
  11.9 在本期输入/证据基础上完成 calibration、champion-challenger 和自动重训闭环。

### 5.3 Runtime parity 与锁闸

比较层级固定为：selection → resolved snapshot/capture → FeatureCell/DQ/provenance → factor → encoded model
input → canonical business prediction。value hash 只标识值内容；`AuditFingerprint` 另覆盖 state、source、
cutoff、DQ、transform 与 route。

- 100% 保存 serving evidence；每份报告确定性抽样 `min(total, max(ceil(total × 10%), 20))`。
- 每 24 小时 full replay 最近 24 小时；schema/transform 变更后及 model publish 前执行 full dataset/model parity。
- source writer 未到 watermark 时记 `PendingMaterialization` 并重试；超过
  `max(10min, 2 × report cadence)` 才判定完整性故障。
- 任一确定性 mismatch：critical alert、revoke 受影响报告、级联失效 intent、打开 parity latch；后续报告、
  model publish 和新入场被阻断，退出/结算继续。
- 恢复必须先通过受影响窗口 full parity，再由 risk owner 提供 actor/reason governed acknowledge。
- Prometheus 标签只允许 stage、feature、reason、model_family、category；禁止任何高基数业务 ID。

### 5.4 UI 业务闭环

新增 **Research > Feature Integrity**：latch、catalog coverage/watermark、最近 sampled/full run、parity age、
趋势和 state/reason 分布；mismatch drawer 并排显示 online/replay value/state、effective/available time、cutoff、
contract/transform hash，并深链 report/model/dataset/job。`Run Full Parity` 与 `Clear Latch` 都是 governed action，
后者只在新 full run 通过后可用。

同步增强：

- Dataset detail：PIT coverage、rejection reasons、FeatureCell 分布、manifest/contracts、integrity gate；仅 Ready 可 Train。
- Model detail：Input Contract / Parity tabs，展示 raw inputs、encoded columns、median/indicator/scaler、训练缺失率、hashes 和 publish gate。
- Report/Recommendation evidence：decision/per-source cutoff、真实 route、FeatureCell/transform/factor revision/input fingerprint。
- Research Jobs：`FeatureParity` 类型、run result 和详情深链。
- 核心诊断结构化展示，raw JSON 只作二级证据；补齐中英文 i18n、backend menu、
  `materialization:read/create` RBAC。

## 6. 生产不变量与失败语义

- **只减一次 lag**：`DecisionBoundary` 外禁止从 decision/as-of 再减 knowledge/source delay。
- **双时间 PIT**：effective 与 available/ingestion 任一越界都不可见；不得用当前投影回填历史。
- **无伪证据**：缺 source 保持 Missing/Unknown，不得伪造 Active、false、2、空字符串或 staleness 0。
- **关键上游输入同样 fail-closed**：Data API position 的 size/value/price/PnL/flags 缺字段即拒绝，
  不得把账户事实补零（字段集合见 [Polymarket positions API](https://docs.polymarket.com/api-reference/core/get-current-positions-for-a-user)）。
  Gamma settlement 只按 winning token identity 映射 primary/secondary；缺失或歧义 outcome 不发布
  `market.resolved`，缺失 `closedTime` 不得用 `updatedAt`/wall clock 代替。
- **共享转换**：fit/apply 是 train/CV/backtest/serving 唯一转换实现；raw feature 与 encoded column 是不同类型。
- **artifact 是真值**：训练不可覆盖 frozen rows；首次激活只从空库生成 v2 dataset/model/artifact。
- **路由 fail-closed**：category 不回退 generic；classical 不调用 factor plane；所有输入绑定真实 model run。
- **parity 与 drift 分离**：parity mismatch 立即锁闸；11.9 的 PSI/KS 只触发 challenger，不能清 parity latch。

## 9. Blocker

以下任一存在即不得宣布 11.6 完成或恢复报告：

- boundary 外二次减 lag，或 live/historical 读取不同来源/字段语义。
- replay 读取 current catalog projection，或 coverage start 前伪造历史版本。
- `fill_missing`、`.__available`、stub market/book、fallback-zero、category→generic fallback 仍可达。
- 训练不消费 frozen artifact，或 model loader 接受 v1/未验证 artifact。
- runtime mismatch 只告警而不 revoke/latch，或无 full parity 即可 acknowledge。
- Dataset/Model/Report/Recommendation 仍只能依赖 raw JSON 才能完成核心 parity 诊断。
- 当前合并态未通过 §8 全量质量门，或 PG/CH 关键集成测试未在可用环境执行。
- 首次激活时 safe v10 config 仍携带 model pointer，或在 full parity/ack 前开启报告。
