# Dead-semantics registry — pending enum variants only.
#
# Every entry here is an enum variant that is DECLARED but not yet CONSTRUCTED in
# production `src/` (excluding tests). Each is tolerated ONLY because it has a
# committed implementation owner in a later Phase 11 sub-phase. When the owning
# sub-phase makes the variant real (i.e. it starts being constructed/emitted in
# production src), the CI gate `scripts/lint-dead-semantics.sh` will FAIL and the
# entry MUST be removed from this file. There is no "permanently allowlisted,
# never emitted" bucket — that is a dead semantic and is forbidden.
#
# Format (whitespace-separated): <Type::Variant>  <owner-phase>  <reason...>
# Lines starting with '#' and blank lines are ignored.

# There are currently no registered-pending enum variants. Structural config
# plans are documented by their owning phase and must not appear in production
# contracts until implemented; they are not allowlisted here.
