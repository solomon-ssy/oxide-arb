## 合并后的唯一语义

11.9 使用三个不可互换的 immutable artifact：

1. `PredictionExplanationArtifact` 只解释模型输出。Weighted model 使用精确闭式分解；
   tree ensemble 使用 exact TreeSHAP，并校验 efficiency。
2. `DecisionCounterfactualArtifact` 在版本化 intervention policy、依赖图和冻结候选集合上重放
   score、rank、TopN 与 decision。它是模型/策略反事实，不是现实世界因果效应。
3. `OutcomeAssociationArtifact` 把 prediction explanation 与 resolution/execution rollup 做带
   不确定性的条件关联。没有明确识别假设时，不得命名为 PnL causal attribution。

执行路径的派生产物同样不修改 canonical truth：

- `ExecutionTrajectoryArtifact` 按 `order_intent_id` 生成 PIT MAE/MFE；
- `PolicyCounterfactualOutcome` 绑定明确的 alternative exit/barrier policy；
- 任何派生结果都不得回填或覆盖 WORM `ExecutionAttemptOutcome` /
  `RecommendationExecutionRollup`。

## Leakage 边界

cycle N 的 recipe planner 只能读取 `available_at <= cutoff` 且属于先前 cycle 或 training cohort 的
attribution artifact。cycle N 的 evaluation/shadow 归因最早从 N+1 开始可用。
