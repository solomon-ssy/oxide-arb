## 合并后的唯一语义

11.9 使用四类不可互换的 immutable artifact：

1. `PredictionExplanationArtifact` 只解释模型输出。Weighted model 使用精确闭式分解；
   tree ensemble 使用 exact TreeSHAP，并校验 efficiency。
2. `DecisionInterventionReplayArtifact` 在真实有向计算图
   `feature → transform → model output → calibration/composite → rank → TopN → decision`
   和冻结候选集合上重放。intervention 必须 feature-specific、domain-admissible、in-support；
   OOD、无实质变化和不可执行 side flip 均保存为 typed `NotEvaluable`，不得静默跳过。
3. `ResolutionOutcomeAssociationArtifact` 把 prediction explanation 与 canonical resolution
   truth 做带不确定性的条件关联。
4. `ExecutionOutcomeAssociationArtifact` 绑定排序后的真实 terminal execution-rollup set，并串联
   recommendation、attempt、partial fill 与 fee。没有明确识别假设时，两类 association 都不得
   命名为 PnL causal attribution。

执行路径的派生产物同样不修改 canonical truth：

- `ExecutionTrajectoryArtifact` 按 `order_intent_id` 生成 PIT MAE/MFE；
- `PolicyCounterfactualOutcome` 绑定明确的 alternative exit/barrier policy；
- 任何派生结果都不得回填或覆盖 WORM `ExecutionAttemptOutcome` /
  `RecommendationExecutionRollup`。

## Leakage 边界

cycle N 的 recipe planner 只能读取 `available_at <= cutoff` 且属于先前 cycle 或 training cohort 的
attribution artifact。cycle N 的 evaluation/shadow 归因最早从 N+1 开始可用。
