# 11.7.1 — 可组合入场条件与 Crypto / Weather 事件闭环

> 状态：**实施中**。本计划破坏式取代 `Immediate | PriceCondition`、`EntryTrigger*`、进程内
> confirmation 与 intent-owned trigger。Phase Exit 要求 Crypto、Weather 两个垂直均完成
> 数据→事件→Recommendation shadow→审计闭环；SemiAuto/AutoExecution 仍受 11.7.2 与本文
> 垂直来源门禁阻断。

## 1. 目标与闭环定位

唯一闭环：

```text
source-native raw fact
  → typed current projection + append-only domain event
  → frozen EntryConditionArtifactV1
  → Recommendation-owned durable instance
  → live / replay byte-identical evaluation
  → ReportOnly shadow / Qualified revocation
  → atomic intent claim + latest admission
  → submission evidence / claim revert
  → condition + execution + resolution attribution
```

固定决策：

1. 条件生命周期属于 Recommendation；ReportOnly 也创建真实 instance、evaluation trace 与 audit。
2. `Qualified` 在原子 claim 前始终可撤销；来源 gap、correction、recross、factor freshness 或绑定漂移
   都会退回 `Waiting/Unavailable` 并重置连续性。
3. `MarketEvent` 只表达离散、可审计的业务状态变化。Crypto 波动冲击、均线交叉、跨源 basis 和
   Weather 概率/离散度均属于 `Factor`。
4. 严禁跨源替代。Chainlink 结算市场只能消费冻结的 Chainlink Data Streams binding；Binance
   只能作为 feature/cross-check。Weather NOAA 是实时代理和预测源，不能冒充 Wunderground
   settlement finalization；真实 label 始终来自 Polymarket winning token。
5. 不提供字符串 event type、JSONPath、SQL、脚本、自由 source、`Not`、compat parser、alias 或
   re-export。

## 2. 删除、合并与破坏式迁移

删除：

- `EntryTrigger`、`EntryTriggerState`、`EntryTriggerObservationView` 与所有 `trigger_*` 列/DTO/UI；
- execution dispatcher 内的条件轮询与进程内 confirmation map；
- intent-owned trigger 状态与批准时创建第二套条件状态；
- Polygon `AggregatorV3` Data Feeds ingestion、round walker、`DomainMetric::OraclePrice`、旧 config/cursor；
- 同 recommendation frozen factor breakdown 充当“最新” exit signal 的路径；
- TradePolicy v1 loader、同步 fit endpoint、fit modal 与未消费的 source/event/config 预留。

迁移 runbook：

1. 暂停新 report/intent；清理所有 pre-submission v1 intent，并在同一事务释放资本。
2. 对 v1 recommendation plan、trade policy、linkage、cursor、旧 Chainlink observations 生成
   content-addressed manifest，核对 row count 与 hash。
3. `Immediate` 迁移为 `EntryConditionPlan::Immediate`；旧价格条件迁移为单 `Price` leaf artifact，
   confirmation 上移到根。历史 instance 只初始化为 `Consumed/Expired/Invalidated`，不恢复活跃连续性。
4. v1 TradePolicy 归档后从运行库删除；linkage v2 的新增 source binding 以迁移时刻作为
   `available_at`，active market 全量重新 resolve，禁止回填历史可见性。
5. 旧 Chainlink facts 必须先 archive seal，再删 row/cursor/code。runtime schema 只接受新版本。
6. dry-run 必须输出 old/new count、payload hash、capital delta 和无法迁移项；rollback 只允许在恢复
   report/intent 前执行，并恢复同一 manifest 快照。切流后回滚方式是切 `ReportOnly`，不是双读 v1。

## 3. 领域契约、状态与存储

```rust
enum EntryConditionPlan {
    Immediate,
    Conditional { artifact_id: EntryConditionArtifactId, content_hash: ContentHash },
}

struct EntryConditionArtifactV1 {
    schema_version: u32,
    evaluator_version: u32,
    binding: EntryConditionBinding,
    confirmation: ConfirmationPolicy,
    root: EntryConditionV1,
}

enum EntryConditionV1 {
    Price(PriceCondition),
    Clock(ClockCondition),
    Factor(FactorCondition),
    MarketEvent { event: MarketEventCondition },
    All { children: Vec<EntryConditionV1> },
    Any { children: Vec<EntryConditionV1> },
}

enum EntryConditionState {
    NotRequired, Waiting, Unavailable, Confirming, Qualified,
    Consumed, Expired, Invalidated,
}
```

`EntryConditionBinding` 冻结 recommendation/market/token/outcome、linkage ID/hash、catalog snapshot、
model/runtime-config、factor definition/hash 和 source binding。任一漂移返回 `Unavailable`，禁止动态换源。

约束：

- confirmation 只在 AST 根；leaf stale、gap、revision 或 unavailable 都重置整体连续性；
- 每组 2–8 child，最大深度 4、最大 32 节点、每次 fit 最多 16 candidates；`Immediate` baseline
  必须且只能出现一次；
- 服务端 flatten 同类组、按 subtree hash 排序、拒绝重复 subtree，并生成稳定 preorder node ID；
- `All`：`Unsatisfied` 优先于 `Unavailable`；`Any`：`Satisfied` 优先于 `Unavailable`；
- canonicalization 后用现有 BLAKE3 `CanonicalDigest` 计算内容地址；不引入第二套 hash。

PostgreSQL：

- `quant_entry_condition_artifact`：content-addressed WORM payload；
- `quant_entry_condition_instance`：Recommendation 唯一实例、state/revision/confirmation/lease/claim；
- `quant_entry_condition_audit`：状态跃迁、lease takeover、claim/revert/expiry WORM audit；
- `quant_crypto_price_projection`、`quant_weather_observation_current`、
  `quant_weather_daily_high_projection`：垂直 typed current projections；
- `quant_domain_source_cursor`：typed checkpoint JSONB + checkpoint hash；
- `quant_market_linkage_source`：linkage-source role child projection。

ClickHouse：

- `quant_crypto_price_report`：Binance aggregate trade / Chainlink signed report；
- `quant_weather_observation_report`：METAR/SPECI/COR/GHCNh 原文、精度、revision/supersedes；
- `quant_weather_forecast_point`：GEFS run/member/valid time/lead/grid binding；
- `quant_domain_event`：仅派生事件；
- `quant_entry_condition_evaluation_event`：紧凑完整树与输入 fingerprint。

raw Crypto 热数据保留 90 天，evaluation trace 30 天，派生事件与 Weather facts 730 天。TTL 清理前必须
生成 content-addressed Parquet partition manifest；未 sealed partition 不允许清理。当前表级无条件 TTL
必须在 Phase Exit 前替换为 archive worker 驱动的显式 partition drop。

## 5. 必建模块与执行路径

### 5.1 Evaluator 与 worker

- 一个纯 evaluator 同时服务 live 与 ordered-fact replay；相同 artifact + facts 必须生成相同 transition、
  evaluation hash 和 input fingerprint。
- Price 只读推荐 token 可执行侧；leaf freshness 与最终 admission book-age 分离。
- Clock 只允许 `RecommendationDecision | MarketStart | MarketEnd + offset`，报告生成时物化绝对 UTC。
- Factor 只读最新持久化 PIT snapshot；同 model 的 composite Factor leaves 必须来自同一完整
  `model_run_id` bundle，不得逐 leaf 拼接不同 serving run。
- worker 接受 BookStore coalesced wake、factor/event notification、clock deadline 与 1 秒 backstop；
  lease 15 秒、5 秒续租。lease epoch 变化时 `Confirming/Qualified` 重置并审计。
- dispatcher 只消费 `NotRequired/Qualified`；claim transaction 同时锁 intent + condition instance，复核
  artifact/hash/revision/evaluation/input fingerprint/admission state version 后转 `Consumed`。
- admission defer/revert 执行 `Consumed → Waiting` 并重新确认；write-ahead submission 成功后证据永久冻结。

### 5.2 Crypto

- Binance：REST 1m kline 保留为 factor/history；新增官方 `aggTrade` WebSocket、trade-ID gap detection、
  REST `/aggTrades` recovery、24h connection rotation 与 archive checksum backfill。
- Chainlink：Data Streams HA WebSocket V3 report、REST `/reports/page` gap recovery 与
  `/reports?timestamp=` reference price；使用 `benchmark_price`，保存 full report hash、feed ID、
  valid/observations/expires timestamps。系统时钟偏差超过 2 秒即 unhealthy。
- `CryptoPriceTransition` 只描述相邻同源价格；artifact 依据冻结 comparator/reference/strike 计算
  opposite→recommended transition，recross 立即撤销未消费资格。
- `ResolutionOracle` 仅 `BinanceKline | ChainlinkDataStreams`；无法识别即 unresolved。

### 5.3 Weather

本期仅支持全球机场“单日最高温”。`WeatherSubject` 冻结 ICAO、IANA timezone、local date、整数温度
band、市场单位、Wunderground 规则 URL、station profile 与 AviationWeather/GHCNh/GEFS bindings。

- AviationWeather：METAR/SPECI/COR 原文 + normalized temperature；同 observation time correction
  追加新 revision，并允许当前日高降低或提高。
- GHCNh：历史 station/QC 与 bias calibration；其下载可见时间是 calibration availability，不能伪造为
  历史 live availability。
- GEFS：`.idx` byte-range 下载 31 members 的 2m TMAX，GRIB2 解码，冻结四点双线性权重；只有形成
  station×lead calibration artifact 后才能输出 bias-corrected forecast feature，禁止写入假零 correction。
- 内部统一 `TemperatureCelsius(Decimal)`；band 比较前转换市场单位，并以冻结
  `MidpointAwayFromZero` whole-degree proxy methodology 量化。
- YES 使用 `WeatherDailyHighEnteredBand`；bounded NO 使用 `WeatherDailyHighExceededBandUpper`；
  open-upper NO 只能使用 `WeatherObservationDayClosedOutsideBand`。
- `WeatherObservationDayClosed` 只表示 NOAA observation-day close，任何页面/事件不得称其为
  Wunderground finalized。

Weather 因子仅在真实 feature consumer 完成后注册：

```text
domain.weather.ensemble_bin_probability
domain.weather.ensemble_spread
domain.weather.observed_high_headroom
domain.weather.noaa_resolution_basis_risk
```

## 6. 生产不变量与来源门禁

所有 missing credential、source gap、binding/hash/version drift、clock skew、forecast member incomplete、
correction conflict 均 fail closed。任何 gate 只保存事实，`TradePolicyArtifact::publication_blockers()`
服务端重算阈值，不信任客户端 `passed`，且无 operator bypass。

| Gate | SemiAuto | AutoExecution |
|---|---|---|
| Chainlink | live shadow ≥14d；≥2,000 个关闭的 5m/15m 市场；reference coverage ≥99.9%；零未解释 direction mismatch；gap 全恢复 | 更严格的 frozen policy gate；不得弱于 SemiAuto |
| Binance | ≥30d overlap；≥100,000 个 1m bar；aggTrade close 与官方 kline 零未解释不一致 | 更严格的 frozen policy gate |
| Weather | ≥500 station-days、20 stations、30 dates；整体 Wilson 95% LB ≥0.95；目标站 ≥20d 后 LB ≥0.90；availability ≥99% | ≥2,000 station-days、30 stations、90 dates；整体 LB ≥0.97；目标站 LB ≥0.95；availability ≥99.5% |

Chainlink 付费/授权是生产依赖；未配置订阅不阻塞无关报告，但所有 bound preflight/publish/evaluation
必须返回 `SourceNotConfigured`。

## 7. API 与操作员工作台

- `GET /quant/recommendations/{id}/entry-condition`
- `GET /quant/recommendations/{id}/entry-condition/audits`
- Intent detail 只嵌同一 instance summary；不得复制 artifact 或建立 intent-owned 状态。
- WebSocket `quant.condition` 只发送 instance ID/revision/state/truth/evaluation hash，客户端再按需拉完整树。
- 删除同步 `/research/trade-policies/fit`，使用 preflight + async fit job + status endpoint。
- Trade Policy Workbench：冻结 dataset/window/runtime/model/source readiness；固定 Immediate baseline；
  typed nested AST editor；canonical tree/natural language/PIT source/blocker；candidate coverage、qualified/
  expired/unavailable/correction revocation、L2 utility、DSR/PBO trial ledger。
- Domain Sources 按 family/source 展示 subscription/checkpoint/lag/gap/revision/archive/basis gate；Linkage
  展示 source roles、Weather station profile/band/settlement rule。
- Recommendation/Intent 展示状态、三态 truth、node evidence、confirmation、short-circuit、audit；窄屏单列，
  状态使用文本+图标+颜色，动态区域 `aria-live`。所有用户文案走 i18n，不依赖 drag reorder。

## 8. 测试与验收

1. AST permutation/hash、flatten、duplicate、depth/node/candidate bounds；三态 All/Any 真值表；root confirmation。
2. Price/Clock/Factor/MarketEvent freshness/binding/PIT；live/replay hash parity。
3. Binance disconnect/rotation/gap/REST/archive；Chainlink V3/HA dedupe/clock skew/reference/secret redaction。
4. METAR/SPECI/COR revision、DST/local-date、日高降低、day close；GEFS idx/range/GRIB/member completeness/
   bilinear weights；GHCNh QC 与 calibration methodology hash。
5. CH replay idempotency；cursor 仅在 raw fact + projection 成功后推进；dual-worker lease/CAS/takeover reset。
6. claim 与 expiry/cancel/report revoke 竞争；admission defer revert；无双提交。
7. Chainlink/Binance/Weather YES/bounded-NO/open-NO E2E；缺 credential/gap/cross-source 失败关闭。
8. ReportOnly 有完整 shadow/audit 且绝不签名提交；UI builder round-trip、keyboard/a11y、desktop/narrow。

质量门使用 Phase README §7 的 Rust/UI 全集；来源 smoke test 必须显式 opt-in，不能让 CI 隐式访问公网。

## 9. Blocker

- 任一旧 `EntryTrigger*`、`ready` condition state、compat loader/alias/re-export 仍在 production path；
- Chainlink 市场可被 Binance event 满足，或 Weather UI 把 NOAA day close 称为 settlement finalized；
- composite Factor leaves 可跨 `model_run_id` 混用；exit 仍复用 recommendation frozen breakdown；
- correction/recross 后 `Qualified` 不可撤销，或 claim 未绑定 revision/input/admission version；
- Weather factor 注册但没有真实 GEFS/GHCNh/AviationWeather consumer；
- archive seal 未实现却由无条件 TTL 删除 facts；
- vertical gate 可由客户端 bool 或 operator bypass 绕过；
- 11.7.2 full-L2/CPCV/DSR/PBO 未通过却发布 SemiAuto/AutoExecution policy。

任一 blocker 存在即 Phase Exit 失败。
