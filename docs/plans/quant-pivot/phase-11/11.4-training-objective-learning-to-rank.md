## 1. 落地目标

把 weighted buy/sell 训练路径升级为按 `as_of` 横截面分组的 learning-to-rank 目标:

```text
RankLoss
  + lambda_tail * TailPenalty
  + lambda_turnover * TurnoverPenalty
  + lambda_l2 * L2
```

本期只落地可解释的 `WeightedFactor` / `HoldVsExitWeighted` 共享 simplex fit。`smartcore 0.5.0`
没有一等 LTR/GBDT ranker, 因此不新增 `GbdtRanker`、`MetaLabeler`、`listwise` 等未实现语义。

## 1.1 加固决策（冻结）

| 决策 | 选择 | 含义 |
|------|------|------|
| TopN 对齐 | **B** | 优化目标仍为 RankIC-weighted RankNet / RankNet；**强制** metrics/UI 输出 `ndcg@k` + `rank_ic`（不进 loss） |
| Lambda 语义 | **B** | 诚实命名 `rank_ic_weighted_ranknet`；simplex surrogate，非 GBDT LambdaRankIC；ties 下限 + 组均值聚合 |
| 伪组合 | **A+** | allocation key = `market_id:token_id`；TopN **score-ranked equal-weight**（禁止 `max(score,0)` 全零塌缩）；UI 标明代理 ≠ backtest |
| Optimizer | **B** | 默认 `coordinate_search`；`argmin` 无 `optimize` feature → 训练 fail-closed |
| Singleton `as_of` | **可观测丢弃** | `<2` 行横截面不进训练；`dropped_singleton_groups/rows` 写入 metrics + summary |
| 覆盖域计数 | **显式** | `rank_loss_group_count`（有 discordant pair 的组）与 `group_count`（tail/turnover 覆盖）区分 |

## 1.2 已知限制（诚实边界）

- Simplex 线性权重 + RankNet 族 surrogate，**不是** XGBoost/LightGBM LambdaMART / LambdaRankIC λ-gradient。
- Coordinate search：固定步长、每轮单改进、全量重算；`argmin` 为可选 refinement。
- Tail/turnover 伪组合 ≠ backtest USD / LP 约束；权威资本路径仍在 backtest/report。
- `held_out_objective`：weighted = `-total_loss`（最后一块）；classical = 滚动 fold 平均 Rank IC（metrics 带 `held_out_metric` 区分）。
- 真实 GBDT LambdaRankIC / listwise / TreeSHAP 解禁 → 后续独立子phase（依赖 11.10）。

## 2. 实现契约

- Runtime config schema **v9**（从 v8 破坏式 bump）。
- `research.training`:
  - `rank_loss = rank_ic_weighted_ranknet | pairwise_ranknet`
  - `optimizer = coordinate_search | argmin`（默认 `coordinate_search`）
  - `lambda_tail`, `tail_fraction`, `lambda_turnover`, `lambda_l2`
  - `ndcg_k`, `pseudo_top_n`（诊断 / 伪组合截断；`1..=reports.max_top_n`）
- 训练 request 不接受临时 objective override。训练任务只引用 frozen `runtime_config_version_id`,
  服务端解析并固化 objective snapshot。
- `quant_model_version.training_objective_json` 非空保存训练目标溯源（spec）。
- artifact 的 `TrainingObjectiveReport` 保存 `spec + components + diagnostics + summary`。
- API `TrainedModelView.training_objective` 返回同一份 provenance。
- metrics: `held_out_objective` / `held_out_components` / `held_out_diagnostics` /
  `held_out_metric` / `dropped_singleton_*` / `fold_components`（破坏式重命名，零兼容）。

## 3. 算法语义

- Query group: 只在同一 `as_of` 横截面内构造 pairwise 排序损失; 禁止跨 `as_of` 混排。
- `pairwise_ranknet`: label 有序 pair 的 logistic loss；组内求和后对有效 group 取均值。
- `rank_ic_weighted_ranknet`: RankIC rank-swap delta 加权 pairwise logistic loss（simplex
  black-box surrogate）。`|Δr̂|_eff = max(|Δr̂|, 1)` 避免 score 打平杀死信号。完整树模型
  λ-gradient 留给真实 ranker 实现。
- **诊断（不进 loss）**: 每组 Spearman Rank IC 与 NDCG@`ndcg_k`（graded relevance =
  `max(label, 0)`），对 in-sample / held-out 分别均值写入 metrics。
- `TailPenalty` / `TurnoverPenalty`: 训练内用 **TopN score-ranked equal-weight** 伪组合
  （token-keyed；全负分仍有非零分配）；真实资金/LP 约束仍由 backtest/report pipeline 验证。
- optimizer 最大化 `-total_loss`; coordinate search 是 deterministic base; `argmin`
  refinement 只在严格改进时接受，且无 feature 时 fail-closed；optimizer 边界 Decimal→f64
  fail-closed（禁止静默 `0.0`）。

## 4. UI / 审计闭环

- 训练弹窗选择 runtime config version 后只读展示 `research.training` snapshot（含
  `ndcg_k` / `pseudo_top_n`）；classical family 显示「不适用」。
- 模型详情展示 `Training Objective` 面板 + 伪组合代理提示；classical / `not_trained`
  不误显 Empty。
- Trainer metrics 展示 in-sample / held-out 的 rank/tail/turnover/L2/total 分解、
  Rank IC / NDCG@k 诊断、`fold_components`、dropped singleton 计数；held-out 标签区分
  LTR composite vs classical Rank IC。
- Classical families 明确标为 pointwise baseline, 不伪装成 LTR objective。

## 5. 删除 / 合并

- 删除旧 `TrainingObjective::RankIc` 单一目标与独立 `Regularization`。
- 删除旧 `penalized_objective = rank_ic - l2` 全局目标。
- 删除 `lambda_rank_ic` 枚举值（破坏式重命名为 `rank_ic_weighted_ranknet`）。
- validation split 从 row-based 改为 group-based, 不再把同一横截面切进不同 fold。
- `mean_objective` → `held_out_objective`（破坏式）。
- 不新增未消费的 GBDT/listwise/meta-label config 或 enum。

## 7. 验收

- group split 不拆分同一 `as_of`。
- 正确排序的 pairwise/lambda loss 小于反向排序。
- RankIC-weighted pair weight 匹配闭式 RankIC swap delta（含 ties 下限）。
- NDCG 完美序 = 1，反序更低。
- TopN 伪组合仅 top-n 行有等权；全负分不塌缩；同 market 不同 token 不合并。
- tail/turnover/L2 component 加权求和等于 total loss。
- `rank_loss_group_count` ≤ `group_count`；全 label-tie 组不计入前者。
- singleton `as_of` 丢弃可观测；错误文案含 `≥2 rows`。
- weighted trainer artifact hash deterministic。
- `argmin` 无 `optimize` feature → 训练 Err。
- runtime-config `research.training` → `TrainingObjectiveSpec` → train E2E（含非默认
  `ndcg_k` / `pseudo_top_n`）。
- runtime schema leaf 包含 `research.training.*`（含 `ndcg_k` / `pseudo_top_n`）,
  `feedback` 空段 skip 保留。
