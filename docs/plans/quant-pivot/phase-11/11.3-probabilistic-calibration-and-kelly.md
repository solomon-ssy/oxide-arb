## 1. 目标与闭环定位

建立"**校准后的概率/收益 → 安全 Kelly**"这条链,替换现有"启发式常数 300/500bps → 直接喂 Kelly"。
两个交付:

1. **概率校准层**:把模型 score 校准到经验频率 `P(win)`,并从 `P(win)` + 校准的收益分布导出
   `expected_return`/`downside`,取代 `HeuristicReturnModel`。
2. **Kelly 安全层**:edge-uncertainty 收缩 + 相关性感知多注收缩 + 总敞口硬上限 + drawdown binding,
   让 sizing 在估计误差下仍然稳健。

闭环定位:11.4(训练)→ 11.5(验证)→ **11.3(校准 + Kelly)**→ 11.7(退出结构消费同一分布)。它是
report sizing 的"最后一公里"正确性。

## 3. 概率校准层(#8, #5)

### 3.1 校准协议(独立 held-out 集,防泄漏)

遵循生产最佳实践(scikit-learn calibration
<https://scikit-learn.org/stable/modules/calibration.html>;workflow
<https://metricgate.com/blogs/workflow-calibrating-predicted-probabilities/>):

- **数据切分**:训练集 / **独立校准集** / 测试集三分,校准器**只在校准集上 fit**,绝不复用训练数据
  (否则校准本身泄漏)。校准集切分必须遵守 11.5 的 purge/embargo。
- **方法选择**:
  - 样本 ≥ ~1000 且畸变非 sigmoid:**Isotonic**(非参单调,能纠任意单调畸变,但需数据量)。
  - 小样本/近 sigmoid 畸变:**Platt / sigmoid**(单参逻辑,数据高效、抗过拟合)。
  - 二分类(YES/NO)天然适配;多结果(neg-risk)用 OvR + 归一化(sum-to-1)。
- **评估**:Brier score + log-loss + reliability diagram;进 11.5 quality gate 与 shadow 漂移监控。
- **漂移**:分布漂移会使校准失效,校准需周期性重拟合(由 11.9 auto-retrain 触发)。

### 3.2 校准 trait 与 artifact

```rust
/// Maps raw model scores to empirically calibrated win probabilities.
/// Fitted ONLY on a held-out calibration split (never on the training split).
pub trait ProbabilityCalibrator {
    fn method(&self) -> CalibrationMethod; // Isotonic | Platt | Beta | Temperature
    fn fit(&self, scores: &[f64], outcomes: &[bool]) -> QuantResult<CalibrationArtifact>;
    fn calibrate(&self, artifact: &CalibrationArtifact, score: f64) -> Probability;
}

pub struct CalibrationArtifact {
    pub artifact_id: CalibrationArtifactId,
    pub method: CalibrationMethod,
    pub model_version_id: ModelVersionId,
    pub feature_schema_hash: Hash,
    pub calibration_split_hash: Hash,      // 校准集 hash,证明独立
    pub reliability: ReliabilityReport,    // bins, Brier, log-loss, ECE
    pub monotone_map: MonotoneMapping,     // isotonic steps 或 platt(a,b)
}
```

### 3.3 校准的收益分布 → return model(#5)

`P(win)` + payout 结构导出收益分布,替换常数上限:

```text
Binary market (buy YES @ price p):
  win  → payout = (1 - p)/p  (每 1 USD 名义)
  loss → payout = -1
  E[r]      = P(win)·(1-p)/p − (1−P(win))          # 校准后的期望收益
  downside  = 经验条件损失(校准集上给定分位的 CVaR)或 max_adverse(11.7 MFE/MAE)
```

`ReturnModelSpec::Calibrated { calibrator_ref, downside_source }`,其中 `downside_source` 可为
`EmpiricalCVaR`(校准集经验)或 `Mfe/Mae`(11.7 三重障碍标注)。**不再有 300/500 常数**。

## 4. Kelly 安全层(#13)

现有分数 Kelly + confidence 收缩 + drawdown 缩放是对的,但**输入 edge 未校准 + 缺三项安全机制**。
补齐(有文献支撑:Advanced Kelly <https://comparenbet.org/guide-advanced-kelly>;Nick Yoder
<https://nickyoder.com/kelly-criterion/>;MacLean-Thorp-Ziemba
<https://www.stat.berkeley.edu/~aldous/157/Papers/Good_Bad_Kelly.pdf>):

### 4.1 Edge-uncertainty 收缩(核心)

Kelly fraction 的正确收缩不是"情绪化回撤",而是**edge 估计本身是随机变量**:估计噪声越大,最优 Kelly
fraction 越小。实现:

```text
f_shrunk = f_kelly * shrink(edge_std)      # edge_std 来自校准的置信区间/回测方差
```

`edge_std` 来源:校准 reliability 的分位置信区间 + 回测(11.5)的 IC 稳定性。**用 shrunk edge,
不用点估计**(与 Munger/Thorp "sandbag your estimates" 一致)。

### 4.2 相关性感知多注收缩

同一 report 的 TopN 是**同时下注**,标准 Kelly 假设独立会过押。近似(comparenbet):

```text
f_i ≈ f_kelly,i / (1 + (n−1)·ρ̄)     # ρ̄ = 平均因子/事件相关
```

复用 11.1 的相关矩阵 + 现有 correlation-cluster caps;`ρ̄` 由 `portfolio/correlation.rs` 提供。

### 4.3 总敞口硬上限

无论个注 Kelly 之和多大,**总同时敞口 ≤ `max_aggregate_exposure_pct`(默认 25%)**;超出则按比例
缩放所有注(comparenbet 的 25% 启发式 + 机构 re-underwriting)。作为 LP 约束进 good_lp
(`Σ u_i ≤ max_aggregate_exposure_pct · bankroll`)。

### 4.4 Drawdown binding(#23 DrawdownCap 落地)

当前 drawdown 只缩放 Kelly fraction。改为**同时**:(a) 继续缩放 fraction,(b) 当 drawdown scaling
成为**实际约束边界**时,`BindingConstraint::DrawdownCap` 被 emit 到 `SizingPlan.binding_constraint`,
让 report 能显示"因回撤被限仓"。消除死语义。

### 4.5 分数 Kelly 默认

生产默认 `kelly_fraction ∈ [0.25, 0.5]`(quarter–half Kelly);money-manager 语义可低至 0.1–0.15
(Nick Yoder)。默认值进 config(不是代码常量),并在 report 标注。

## 6. 生产不变量与失败语义

- **未校准 fail-closed**:`uncalibrated` return model 禁止 publish、禁止建 intent、禁止 auto/semi。
  只允许 report_only 的"实验性 shadow report"且明确水印。
- **校准集独立**:calibrator fit 数据必须与训练集不相交(hash 校验),否则拒绝 artifact。
- **Kelly 单调安全**:任何安全机制只会**缩小**仓位,不会放大(边界证明 + 测试)。
- **总敞口硬上限**:LP infeasible 时 fallback 仍受 25% 约束。
- **DrawdownCap 语义精准**:仅当 drawdown 真正是 binding 边界时 emit。
- 货币域全程 Decimal;校准器 f64 仅在 calibrate 边界,输出 clamp 到 `Probability` [0,1]。
