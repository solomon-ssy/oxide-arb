## 2. 唯一闭环对照

契约闭环：

```text
source-native raw fact
  → typed current projection + append-only domain event
  → frozen EntryConditionArtifactV1
  → Recommendation-owned durable instance
  → live / replay byte-identical evaluation
  → ReportOnly shadow / Qualified revocation
  → atomic intent claim + latest admission
  → submission evidence / claim revert
  → condition + execution + resolution attribution
```

| 闭环段 | 实现锚点 | 状态 | 审计注记 |
|--------|----------|------|----------|
| source-native raw fact | Binance aggTrade / Chainlink V3 / METAR / GHCNh / GEFS | Partial | 主路径落地；Binance archive checksum backfill 缺失；Chainlink live timestamp gap 弱于 Binance |
| typed projection + domain event | PG projection + outbox → CH `domain_event` | OK | 同源 projection、revision、day-close、crypto transition 事件已接线 |
| frozen EntryConditionArtifactV1 | content-addressed WORM + AST canonicalize | OK | Immediate \| Conditional；根 confirmation；flatten / sort / dedupe；BLAKE3 CanonicalDigest |
| Recommendation-owned instance | composer 创建 shadow instance | OK | ReportOnly 也创建真实 instance；intent 只嵌 `instance_id` |
| live / replay byte-identical | `evaluate_entry_condition` 纯函数 | Partial | 同函数 hash parity 单测有；无 CH ordered-fact replay worker / E2E |
| ReportOnly shadow / Qualified revoke | worker 全模式 + FSM | Partial | shadow 路径真；recross→Waiting 真；但 crypto Entered 是 level 非 edge；report revoke 不 invalidate condition |
| atomic claim + admission | intent + condition 同事务 claim | OK+ | revision / hash / fingerprint / admission_version 复核；post-claim revert Consumed→Waiting |
| attribution / vertical gates | `publication_blockers` + gate schema | Defer\* | 门禁 schema 正确且 fail-closed；证据采集属 W7；11.7.2 研究激活另议 |

## 4. 发现（按严重度）

### P0 — 硬阻断

#### P0-1. `CryptoSubjectPredicateEntered` 语义错误：level-triggered

- **证据**：`evaluate_crypto` 只用 `current_price`；`previous_price` 加载却不参与「从 opposite 进入 recommended」。已在 recommended 侧的市场会直接 `Satisfied`，无「进入」边。单测 `crypto_recross_revokes_*` 只验证离开→`Unsatisfied`，掩盖了假阳性。
- **锚点**：`crates/quant-pivot-core/src/execution/entry_condition.rs`（`evaluate_crypto`）
- **生产级修复**：改为 transition 判定：`previous outcome ≠ recommended ∧ current == recommended`；首 tick previous 缺失 → `Unavailable` 或显式 NotYetEntered；更新单测覆盖 already-on-side / first-tick。

#### P0-2. Intent expiry / report revoke 未与 condition 原子终态耦合

- **证据**：11.7 §6 要求 expiry 同事务把 intent + condition → `Expired`。实际 `order_intent::expire` 只改 intent + 释放资本；condition 靠独立 `expire_due`。`IntentInvalidationHook` 只 invalidate intents。ReportOnly shadow 下 `Qualified` 可在 report revoke 后残留。
- **锚点**：`crates/quant-pivot-repository/src/postgres/quant/order_intent.rs` · `entry_condition.rs` · `intent_service.rs`
- **生产级修复**：expire / cancel / revoke 路径同事务锁 intent + condition，条件更新为 `Expired` / `Invalidated` 并写 WORM audit；补 claim vs revoke 竞态测。

#### P0-3. Archive seal 未实现 + 遗留无条件 TTL

- **证据**：计划 §9 blocker：未 sealed 禁止清理。无 `archive_seal` / Parquet partition manifest worker。`quant_domain_observation` 仍有 `TTL … DELETE`；新 domain 表暂无 TTL 只是暂避。
- **生产级修复**：实现 seal → manifest → 显式 drop；删除 / 替换无条件 TTL；CI 断言新表无盲目 DELETE TTL。

### P1 — 语义 / 闭环质量

| # | 问题 | 证据 | 生产级修复方向 |
|---|------|------|----------------|
| P1-1 | `continuity_hash` 对 revision / factor / report 变化失明 | `continuity_projection` 仅 `gap_generation`(+source)；Weather COR 后仍 Satisfied、Factor 换 `snapshot_hash`、Crypto `report_hash` 变化时可能不重置 `confirmation_started_at` | 把 weather.revision、factor.snapshot_hash / model_run_id、crypto.report_hash \| source_sequence 纳入 continuity；校正 / 刷新必断连续窗口 |
| P1-2 | `SourceNotConfigured` / `SourceGap` 死语义 | 枚举存在但评估路径从不 emit；缺 credential 的 Chainlink binding → `InputMissing` / `SourceUnhealthy`。违反「类型要么生产 emit 要么删除」 | input provider 在 binding 存在但 deploy secret / source 未配置时 emit `SourceNotConfigured`；gap 检测 emit `SourceGap` 或删除未用变体 |
| P1-3 | GEFS bias 是 ephemeral fit，非 WORM calibration artifact | `fit_lead_biases` 在特征构建时窗口内拟合；hash 进 evidence，但不落 station×lead calibration artifact。缺样本 → `NullReason`（非假零）是对的，但契约「artifact 后才能 bias-correct」未落地 | 引入 content-addressed station×lead calibration artifact；特征只消费已发布 artifact，禁止 inline 临时 fit 冒充 |
| P1-4 | Binance archive backfill 配置空转 | `archive_url` 在 `domain_sources` 存在，无 reader / worker / checksum 校验路径 | 实现 vision archive 拉取 + checksum 对账 + cursor；或删除未接线配置字段 |

| P1-6 | UI 操作员闭环未达 §7 | evaluator 有 `ConditionNodeEvaluation`；API / UI 不导出。Unavailable 只显示 kind。Workbench 暴露 DSR / PBO / L2 旋钮但后端 `trial_ledger` / `full_L2` 恒空——像 11.7.2 已可用。Domain Sources 缺 gap / revision / archive / basis | API 导出 evaluation tree + evidence + short-circuit；UI 展示；Workbench 明确 11.7.2 Incomplete banner；补 ReportOnly shadow E2E + `quant.condition` WS 测 |

### 操作员闭环判断

- **后端**：ReportOnly 注册同一 durable worker；composer 创建真实 shadow instance；不签名不提交 — **闭合**。
- **UI**：操作员可手动打开 recommendation condition tab 看状态 / 树 / audit，但缺 list 级可见性、node evidence、原因下钻、ops console — **半闭合**。
- **E2E**：无自动化证明「ReportOnly recommendation → Waiting→Confirming→Qualified + audit，且永不 submit」— **未闭合**。

## 8. 设计上做得对的地方（应保留）

### 领域边界

MarketEvent vs Factor 切分正确；严禁跨源替代；`ResolutionOracle` 仅 `BinanceKline | ChainlinkDataStreams`；Polygon AggregatorV3 / `EntryTrigger*` 已从生产路径清除。

### 状态归属

Condition 属 Recommendation；intent 只引用 instance；原子 claim 复核 artifact / revision / evaluation / input / admission — TOCTOU 关闭方式正确。

### 研究激活诚实性（后端）

`vertical_gate_evidence` 空 → `MissingVerticalGateEvidence`；full-L2 / trial ledger 空 → 不可 Publish。后端不会用客户端 `passed` 绕过。这是生产级 fail-closed，应保留。

### Weather 代理诚实性

NOAA day-close ≠ Wunderground finalized 在事件命名与 linkage UI 已体现；与 Polymarket 真实结算源文献一致。整度代理与 basis 因子分工合理。

### 其它亮点

- 单一纯 evaluator 服务 live 与（至少 unit 级）replay
- Factor 同 `model_run_id` bundle 完整性校验
- Lease 15s / renew 5s；lease epoch 变化重置 Confirming / Qualified
- Dispatcher 只消费 `NotRequired | Qualified`
- Weather 四因子均有真实 feature consumer，非空注册

## 10. 优先修复顺序

不要用「最小侵入」绕过 edge 语义或终态耦合。

1. Crypto edge-enter（transition 判定 + 单测）
2. expiry / revoke ↔ condition 原子终态
3. continuity 纳入 revision / factor / report
4. archive seal（manifest → 显式 drop；替换无条件 TTL）
5. `SourceNotConfigured` 真发射（或删除死变体）
6. UI evidence + 诚实 11.7.2 banner + ReportOnly E2E

同步建议（可与上并列）：

- GEFS WORM calibration artifact
- Binance archive backfill 或删配置
- Chainlink live timestamp gap + REST 回填
- Dual-worker lease takeover PG 集成测
- 文档：RFC 8785 引用与实现对齐

## 11. Phase Exit 判定（相对计划 §9 Blocker）

| Blocker | 是否仍存在 |
|---------|------------|
| 旧 `EntryTrigger*` / compat loader / re-export 仍在 production path | **否**（生产路径已清；注释 / 旧文档残留） |

| claim 未绑定 revision / input / admission version | **否** |
| Weather factor 注册但无真实 consumer | **否** |
| archive seal 未实现却由无条件 TTL 删除 facts | **是** |
