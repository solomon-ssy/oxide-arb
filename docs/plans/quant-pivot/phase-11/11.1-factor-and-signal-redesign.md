## 1. 目标与闭环定位

把在线信号从"流动性 + 价差 + 简单动量"三因子线性排序器,重构为**语义清晰、正交、可学习归一化、
全截面标准化**的因子体系。它是 Phase 11 阿尔法链的第一环:在线闭环 `MarketSelection → FeatureVector
→ FactorValue → ModelRun` 中的 `FactorValue` 层重构,并为 11.4(训练目标)提供**低共线、可解释**的
因子输入。

设计立场(有文献支撑):

- 因子必须先有清晰经济含义,再工程化;归一化必须**逐日逐特征在截面上**做(winsorize → z-score 或
  rank),否则截面信息被稀释。见 Coqueret & Guida *ML for Factor Investing* Ch.4
  (<https://www.mlfactor.com/Data.html>)与截面算子规范
  (<https://docs.skelfresearch.com/sigc/operators/cross-sectional/>)。
- 因子间要正交化,避免"动量因子 = 收益因子"这类共线冗余(见
  <https://stockalpha.ai/alpha-learning/custom-factor-investing-building-your-own-alpha-factors>)。

## 3. 契约与算法设计

### 3.1 独立动量因子族(修复 #2)

用与 `simple_return` 语义**不同**的估计量,消除共线:

| 因子 | 定义 | 说明 |
|---|---|---|
| `momentum.roc_{W}` | Rate of change 但**跳过最近 lag L**(`(mid_{t-L} - mid_{t-W}) / mid_{t-W}`) | 经典 12-1 动量思想:排除最近反转段 |
| `momentum.ema_slope_{W}` | EMA(W) 的斜率 / EMA(W) | 趋势强度,平滑抗噪 |
| `momentum.vol_adjusted_{W}` | `return_{W} / realized_vol_{W}`(风险调整动量) | Baz 风格 vol-normalized(见 LTR 论文 §基线) |
| `momentum.macd_norm` | `(EMA_fast - EMA_slow) / realized_vol` | vol-normalized MACD |

`ts.return_{W}` 保留为**特征**(feature 层),但**不再直接作为动量因子的输入**;动量因子只吃上面的
派生估计量。共线检测(§3.4)在 CI/训练时强制。

### 3.2 归一化参数化(修复 #3)

删除代码里的 logistic `k`/`x0` 常量。**已落地**的 `FactorNormalization` 契约(`quant-pivot-models`
`enums/factor.rs`)——只含本期实际 emit 的方法(零死语义),数值参数全部来自
`factors.normalization` config:

```rust
/// The normalization METHOD (semantic contract, in definition_json + factor_schema_hash).
/// Distributional params (winsor_p / clamp_sigma / min-max bounds) come from runtime config.
pub enum FactorNormalization {
    /// Cross-sectional winsorize to [p, 1-p] then z-score, ±σ clamped.
    WinsorizedZScore,
    /// Cross-sectional average rank mapped to [0, 1] (distribution-free).
    Rank,
    /// Per-market min/max against a semantic domain (bounds from config, e.g. data_quality∈[0,1]).
    MinMax,
}
```

默认:generic 因子默认方法 `WinsorizedZScore`,参数由 `factors.normalization.default_winsor_p=0.01`
+ `default_clamp_sigma=3` 提供(winsorize 1%/99% → z-score → ±3σ clamp,见 mlfactor Ch.4);
`liquidity_depth / volatility_regime / time_to_resolution` 用 `Rank`;`data_quality` 用 `MinMax`
(界值经 `factors.normalization.per_factor` 提供,不进代码)。

> **延后(见 §10)**:`RankCentered`(signed,Kelly-Pruitt-Su)与 `Uniformize`(ECDF)在本期无默认
> 因子使用,按零死语义**不加入枚举**,由 **11.4** 在 LTR 需要 signed/ECDF 归一化时引入;
> `FittedMonotone { calibrator_ref: CalibrationArtifactId }`(离线拟合的单调校准)由 **11.3** 随
> 校准器与 `CalibrationArtifactId` 一并引入(`CrossSectionalNormalizer` trait 即扩展缝)。

### 3.3 全截面 batch 归一化 stage(修复 #3 的 rank/zscore 需 batch)

`FactorEngine` 增加两阶段:

1. **raw stage**(逐市场,纯):算每个因子的 `raw_value`(如 winsorize 前的原值)。
2. **cross-section stage**(全截面 batch):在同一 `as_of` 的整个 selection 上算 winsorize 边界、
   均值/标准差、rank,产出 `normalized_score`。

```rust
pub trait CrossSectionalNormalizer {
    /// Compute normalization statistics over the full cross-section at one as_of.
    fn fit(&self, raw: &[RawFactorColumn]) -> QuantResult<NormalizationStats>;
    /// Apply frozen stats to each market's raw value (audited clamp).
    fn apply(&self, raw: &RawFactorColumn, stats: &NormalizationStats) -> Vec<NormalizedFactor>;
}
```

单市场/极小截面(n < `min_cross_section`)处置(**不静默 0.5**):

- 若有 report-history:用**历史滚动分位**归一化,并标 `NormalizationSource::HistoricalQuantile`。
- 否则:因子输出 `Indeterminate { reason: CrossSectionTooSmall }`,scorer 端 `confidence=0` 且
  `contributes=false`(已有语义),**记录原因**,而非伪造中性 0.5。

### 3.4 因子正交化与共线门禁(修复 #2 根因)

- 训练/回测时计算因子间 **Spearman 相关矩阵**;任一对 |ρ| > `max_factor_correlation`(默认 0.9)
  触发 `FactorCollinearityWarning`,publish gate 硬失败(除非显式 `orthogonalize` 或删因子)。
- 可选 `neutralize(by = category)`:把因子对 category dummy 回归取残差(sector-neutral 思想),
  避免 category 泄漏(见 skelf `neutralize`、stockalpha 行业中性)。

## 4. 默认因子集(修复 #1)

`FactorsConfig::default` 改为启用全部通用因子家族。落地后生产默认因子:

| 家族 | 因子 | 归一化 | required |
|---|---|---|---|
| liquidity | `liquidity_depth`, `spread_efficiency` | Rank / WinsorizedZScore | yes |
| book | `book_imbalance` | WinsorizedZScore | no |
| momentum | `momentum.roc`, `momentum.vol_adjusted`, `momentum.macd_norm` | WinsorizedZScore | no |
| reversal | `mean_reversion`(独立于动量,见 §3.1/#2) | WinsorizedZScore | no |
| volatility | `volatility_regime` | Rank | no |
| activity | `market_activity` | WinsorizedZScore | no |
| resolution | `time_to_resolution` | Rank | no |
| quality | `data_quality` | MinMax(阈值入 config) | no |

启用不等于等权:权重仍由 11.4 训练学习;默认未训练时用**等权 + confidence 加权**并在 report 标注
"untrained default weights"(与"零死语义"一致:默认权重是显式声明,不是隐藏常量)。

## 5. deploy-config key 与 runtime-config schema path

`factors` 段(v10)扩展:

```text
factors.enabled_families           = [liquidity, book, momentum, reversal, volatility, activity, resolution, quality]

```

## 6. 生产不变量与失败语义

- **截面归一化无魔法常量**:所有 winsor/clamp/rank 参数来自 config 或 fitted artifact。
- **无静默 0.5**:小截面/缺输入 → `Indeterminate` + reason,不伪造中性值。
- **共线门禁**:|ρ|>阈值 且未正交化/未删因子 → publish 硬失败。
- **在线/离线同一定义**:同一 `FactorEngine` + 同一 `CrossSectionalNormalizer` 服务 online 与
  backtest(与 11.6 训练-服务一致性绑定)。
- PIT:cross-section stage 只用同一 `as_of` 的截面,不跨 as_of 借用统计。

## 7. 第三方 crate 引入

- 复用既有 `ndarray` / `ndarray-stats`(quantile/rank/correlation,均 base dep)、`statrs`。
- 无新增 crate。winsorize/zscore/rank/spearman 用 `ndarray-stats`。

## 8. 验收测试

- `momentum_roc_not_equal_simple_return`(断言动量因子与 `ts.return` 数值不同、相关 < 阈值)。
- `cross_sectional_zscore_mean_zero_std_one_per_as_of`。
- `winsorize_caps_at_configured_percentile`。
- `small_cross_section_yields_indeterminate_not_half`(#3 no-silent-neutral)。
- `default_factor_config_enables_all_generic_families`(#1)。
- `collinearity_gate_blocks_publish_when_rho_exceeds_threshold`(#2 根因)。
- `normalizer_has_no_hardcoded_k_x0`(grep 断言 generic.rs 无 logistic 常量)。
- `online_and_backtest_use_same_normalizer`(与 11.6 共享测试)。

## 9. Blocker

- 任一因子仍用代码内硬编码归一化常量。
- 动量因子与收益特征相关系数仍 > `max_factor_correlation`。
- 小截面仍落到静默 0.5。
