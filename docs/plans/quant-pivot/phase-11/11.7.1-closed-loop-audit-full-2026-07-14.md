## 2. 唯一闭环对照

### 2.1 契约闭环

```text
source-native raw fact
  → typed current projection + append-only domain event
  → frozen EntryConditionArtifactV1
  → Recommendation-owned durable instance
  → live / replay byte-identical evaluation
  → ReportOnly shadow / Qualified revocation
  → atomic intent claim + latest admission
  → submission evidence / claim revert
  → condition + execution + resolution attribution
```

### 2.2 分段判定

| 闭环段 | 实现锚点 | 状态 | 审计注记 |
|--------|----------|------|----------|
| source-native raw fact | Binance aggTrade / Chainlink V3 / METAR / GHCNh / GEFS | **Partial** | 主路径落地；`archive_url` 未接线；Chainlink live timestamp gap 弱于 Binance；session 启动无条件 `mark_*_source_gap` |
| typed projection + domain event | PG projection + outbox → CH `quant_domain_event` | **OK** | 同源 projection、revision、day-close、`CryptoPriceTransition` 已接线；评估器读 projection 非 CH 事件流 |
| frozen `EntryConditionArtifactV1` | content-addressed WORM + AST canonicalize | **OK** | `Immediate \| Conditional`；根 confirmation；flatten / sort / dedupe；BLAKE3 `CanonicalDigest` |
| Recommendation-owned instance | `composer` 创建 shadow instance | **OK** | ReportOnly 也创建真实 instance；intent 只嵌 `instance_id` summary |
| live / replay byte-identical | `evaluate_entry_condition` 纯函数 | **Partial** | 同函数 hash parity 单测有；无 CH ordered-fact replay worker / E2E |
| ReportOnly shadow / Qualified revoke | worker 全模式 + FSM | **Partial** | shadow 路径真；recross→`Waiting` 真；crypto Entered 是 level；report revoke 不 invalidate condition |
| atomic claim + admission | intent + condition 同事务 claim | **OK+** | revision / hash / fingerprint / `admission_state_version` 复核；post-claim revert `Consumed→Waiting` |
| attribution / vertical gates | `publication_blockers` + gate schema | **Defer\*** | 门禁 schema 正确且 fail-closed；证据采集属 W7；11.7.2 研究激活另议；11.8–11.10 归因另议 |

### 2.3 数据平面架构（as implemented）

```text
Linkage discovery（active markets，LiveEvent role only）
  → quant-pivot-api adapters
       Binance aggTrade WS + REST recovery
       Chainlink Data Streams HA WS V3 + REST page/reference
       AviationWeather METAR/SPECI/COR
       GHCNh historical PSV
       GEFS .idx byte-range + GRIB2 TMAX（31 members）
  → ClickHouse raw facts
       quant_crypto_price_report
       quant_weather_observation_report
       quant_weather_forecast_point
  → PgDomainProjectionRepository（原子 PG projection + cursor + outbox）
       quant_crypto_price_projection
       quant_weather_observation_current
       quant_weather_daily_high_projection
       quant_domain_event_outbox
  → DomainEventOutboxWorker → quant_domain_event（CH）
  → EntryConditionWorker
       LiveEntryConditionInputProvider（PG projections + BookStore + factor bundle）
       evaluate_entry_condition → apply_evaluation → CH evaluation trace
  → WeatherDomainFeatureBuilder → 4 domain factors（真实 consumer）
```

**注记**：命名上「event-driven」指 PG `LISTEN` wake（`crypto` / `weather` / book / factor / clock），非直接消费 `quant_domain_event` 流做 leaf 判定。Domain event 是派生、可审计事实；MarketEvent leaf 评估的是 **current projection 状态**。

## 5. 发现（按严重度）

### P0 — 硬阻断

#### P0-1. `CryptoSubjectPredicateEntered` 语义错误：level-triggered

- **证据**：`evaluate_crypto` 只用 `current_price`；`previous_price` 加载却不参与「从 opposite 进入 recommended」。已在 recommended 侧的市场会直接 `Satisfied`，无「进入」边。单测 `crypto_recross_revokes_*` 只验证离开→`Unsatisfied`，掩盖 already-on-side 假阳性。
- **锚点**：`crates/quant-pivot-core/src/execution/entry_condition.rs`（`evaluate_crypto`、`crypto_outcome`）
- **生产风险**：Chainlink 15m/5m 市场可能在报告生成后即 Qualified，无真实 crossover 事件；与计划 §5.2 `CryptoPriceTransition` / entered 语义矛盾。
- **生产级修复**：
  1. transition 判定：`crypto_outcome(previous) ≠ recommended ∧ crypto_outcome(current) == recommended`
  2. 首 tick `previous` 缺失 → `Unavailable(NotYetEntered)` 或等价 typed reason（非 `InputMissing` 静默 skip）
  3. 单测：already-on-side、first-tick、true crossover、recross 四条路径

#### P0-2. Intent expiry / report revoke 未与 condition 原子终态耦合

- **证据**：11.7 §6 要求 expiry 同事务把 intent + condition → `Expired`。实际：
  - `order_intent::expire` 只改 intent + `release_capital`
  - `entry_condition::expire_due` 是独立 sweep（`entry_condition_worker` + `intent_service` 各跑各的）
  - `ReportLifecycleService::revoke` → `IntentInvalidationHook` 只 invalidate intents，不 touch condition
- **锚点**：
  - `crates/quant-pivot-repository/src/postgres/quant/order_intent.rs`（`expire`）
  - `crates/quant-pivot-repository/src/postgres/quant/entry_condition.rs`（`expire_due`）
  - `crates/quant-pivot-core/src/execution/intent_service.rs`（`expire_due`）
  - `crates/quant-pivot-core/src/report/lifecycle.rs`（`revoke` / `cascade_intent_invalidation`）
- **生产风险**：ReportOnly shadow 下 report revoke 后 condition 可残留 `Qualified`；操作员监控语义错误（admission 会因 report 状态 defer，但 shadow 不可信）。
- **生产级修复**：expire / cancel / report-revoke 路径同事务锁 intent + condition → `Expired`/`Invalidated` + WORM audit；补 claim vs revoke 竞态集成测。

#### P0-3. Archive seal 未实现 + 遗留无条件 TTL

- **证据**：计划 §9 blocker：未 sealed 禁止清理。无 `archive_seal` / Parquet partition manifest worker。`quant_domain_observation` 仍有 `TTL … 730 DAY DELETE`；新 domain 表暂无 TTL 只是暂避无界增长。
- **锚点**：`crates/quant-pivot-storage/src/clickhouse/sql/`；全仓无 `archive_seal` 实现
- **生产级修复**：seal → content-addressed Parquet manifest → 显式 partition drop；删除/替换无条件 TTL；CI 断言新表无盲目 DELETE TTL。

## 9. 设计上做得对的地方（应保留）

### 9.1 领域边界

- `MarketEvent` vs `Factor` 切分正确；严禁跨源替代。
- `ResolutionOracle` 仅 `BinanceKline | ChainlinkDataStreams`。
- Polygon `AggregatorV3` / `EntryTrigger*` 已从生产路径清除。

### 9.2 状态归属与执行门禁

- Condition 属 Recommendation；intent 只引用 instance。
- 原子 claim 复核 artifact / revision / evaluation / input / admission — TOCTOU 关闭方式正确。
- Dispatcher 只消费 `NotRequired | Qualified`。
- Lease 15s / renew 5s；lease epoch takeover 重置 Confirming / Qualified 并审计。

### 9.3 研究激活诚实性（后端）

- `vertical_gate_evidence` 空 → `MissingVerticalGateEvidence`。
- full-L2 / trial ledger 空 → 不可 Publish。
- 不信任客户端 `passed`；无 operator bypass。

### 9.4 Weather 代理诚实性

- NOAA day-close ≠ Wunderground finalized（事件命名 + linkage UI）。
- 整度 `MidpointAwayFromZero` 冻结代理；basis 由 `noaa_resolution_basis_risk` 因子承载。
- 四因子均有真实 feature consumer；缺 GEFS/GHCNh → `NullReason` 非假零。

### 9.5 训练-服务 / Exit

- 单一纯 evaluator 服务 live 与（至少 unit 级）replay。
- Factor 同 `model_run_id` bundle 完整性校验。
- Exit reinference 用 `latest_snapshot_bundle`，非 recommendation frozen breakdown。
